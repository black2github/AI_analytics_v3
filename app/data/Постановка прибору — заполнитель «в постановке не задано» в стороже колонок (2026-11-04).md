# Постановка прибору — заполнитель «в постановке не задано» в стороже колонок таблиц (2026-11-04)

Для сессии «Правки прибора, акцепт и рутина». Причина установлена; ниже диагноз, целевое поведение, тесты. Коммит в analyzer — по слову владельца в чате сессии; копия в канон — через владельца (worktree, команды по одной).

## Диагноз

`normalize_tables.py --check` по карточкам интерфейса модуля КК (`docs/modules/widgets-rtl/interface/mod-widgets-rtl-001…004`) даёт по две ✗ на таблицу параметров:

```
колонка «Код параметра» (роль: путь): валидных 0.0% [0/4] ✗ НИЖЕ ПОРОГА
колонка «Кратность» (роль: кратн): валидных 0.0% [0/4] ✗ НИЖЕ ПОРОГА
```

Ячейки этих колонок заполнены ровно «в постановке не задано». Это канонический заполнитель пробела источника: шаблон `module-interface.md` (канон a696b8e) в примере карточки заполняет им те же колонки (строки примера «Входные параметры»), `rules/defaults.md` говорит «в режиме A (reverse) пробел источника остаётся «в постановке не задано»», `content.py` знает формулу (`_SILENT_FORMULA`). Сторож колонок `kitcheck/columns.py` (`check_columns`, роли «путь» `_looks_like_path`, «кратн» `_looks_like_cardinality`, «обязат») заполнитель не знает и считает ячейку невалидной; послабление `source_literals` не помогает — в источнике таблицы нет (параметры перечислены списком `<ul>`). Итог: карточка, сделанная строго по шаблону, получает ✗ от прибора. Ложный брак, а не дефект карточки.

## Целевое поведение

- В `check_columns` ячейка, равная заполнителю «в постановке не задано» (после `strip`, без учёта регистра первой буквы; с разметкой жирным/курсивом — снять как у других значений), считается валидной в любой роли (путь, кратн, обязат, пары). Константу взять одну на прибор — `_SILENT_FORMULA` из `content.py` вынести в общее место (`kitcheck/md.py` или `columns.py`) и импортировать в обоих, чтобы формула жила в одном доме.
- Ничего иного не меняется: другие заполнители («—», пусто, «не задано», «n/a») — как прежде (пустая строка в роли «путь» и так валидна — оставить); порог и текст строки отчёта прежние; `source_mode` без изменений.
- Слой — ядро (общий для всех утилит).

## Тесты (срабатывание и несрабатывание)

- Таблица параметров с четырьмя строками, в колонках «Код параметра» и «Кратность» везде «в постановке не задано» → по этим колонкам ✗ нет (валидных 100%).
- Та же таблица, но в одной ячейке «не задано» (без «в постановке») → ✗ как прежде (валидных 75%, ниже порога — по текущему порогу).

- Роль «обязат»: «в постановке не задано» валидна; «Да»/«Нет» — как прежде.
- Регресс: `tests/test_normalize_tables.py`, `tests/test_kitcheck_core.py`, `tests/test_branch_form_normalize.py`, `tests/test_selfcheck_titles.py` зелёные (базлайн снять до правок).
