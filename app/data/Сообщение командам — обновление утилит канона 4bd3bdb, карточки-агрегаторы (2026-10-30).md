# Сообщение командам — обновление утилит канона (master 4bd3bdb, 2026-10-30)

Для всех команд, работающих по канону (координаторы и исполнители). Команде КК отдельно передано то же с её перечнями. Передаёт владелец канона.

---

Коллеги, в каноне (`_meta/tools/`) обновлён гейт карточки, обновите клон перед прогонами:

```
git -C <клон канона> pull --ff-only
```

1. **Карточки-агрегаторы нескольких страниц.** Если карточка собирает несколько страниц-источников (несколько `confluence_page_ids`) или это файл справочников `dictionaries.md` по шаблону data-model, дословное равенство `title` заголовку главной страницы больше не единственный способ пройти title-страж: карточка проходит, если наименование **каждой** страницы-источника стоит в ней заголовком раздела любого уровня, дословно и с ведущим тегом страницы (ведущий номер раздела допускается). Имя в абзаце или ячейке таблицы заголовком не считается. Обычные карточки с одной страницей — без изменений: title дословно. При нехватке отчёт перечисляет недостающие наименования: «title: карточка-агрегатор N страниц — нет заголовков по страницам: …». Норма — `_meta/templates/data-model.md`, раздел «Шаблон dictionaries.md».

2. **Кавычечные литералы источника** ищутся теперь не только в группе карточки и её каталоге, но и во всех артефактах комплекта, привязанных к той же странице (например, когда термины страницы ушли в глоссарий, а принципы — в процесс). В отчёте появляется информационная строка «i кавычечные литералы ×N найдены в артефактах той же страницы (<файлы>)». Литерал, которого нет нигде, по-прежнему ✗.

Команды, ключи, отчёты и коды возврата те же; эталонный комплект проходит без отличий. Бандл экспортёра не затронут. Вопросы — владельцу канона.
