Отсутствие файла по ссылке на sidecar, пустой файл (0 байт или только пробелы), нечитаемый файл — ✗ как прежде; если сторожа отсутствия/пустоты сейчас нет — завести (это и есть «брак переноса» по решению).

5. **Итог.** В сводке selfcheck (`# ИТОГО: файлов N — ✓ / ✗ / ⚠`) — отдельный счётчик `⚠ примеры: K` (K не входит в общий ⚠ или входит — на ваш выбор, но строка отдельная); в отчёте по карточке строки класса начинаются с `⚠ примеры:`. Вердикт карточки и комплекта по классу «примеры» не меняется (не БРАК). `normalize --check` — те же классы.
