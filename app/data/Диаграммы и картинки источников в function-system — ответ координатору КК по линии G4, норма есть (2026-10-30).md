# Диаграммы и картинки источников в карточках function/system — ответ координатору КК по системной линии G4 (2026-10-30)

Передаёт владелец канона. Ответ на «кандидат OQ на решение владельца» из отчёта `sandbox/review-5.2-G4-r01.md` (mermaid/img не перенесены в fun-sys-05/06/07, Visio у fun-sys-15). Решение владельца канона 30.10: норма переноса уже есть, новую не заводим, OQ на линию не нужен.

---

Коллеги, по линии диаграмм и картинок из G4: канон переноса есть, он общий для всех типов карточек, подтверждаю его для function/system. Три случая, три правила:

1. **Текст диаграммы (mermaid в источнике)** — это текст страницы, переносится дословно блоком кода ` ```mermaid ` в карточку, как любой текст источника. Прецедент в самом комплекте: OQ-287 (PIN-05, PROC-043) — «mermaid-текст источника перенесён дословно». Отсутствие — класс «потеря содержимого», линия 2, исполнитель.
2. **Растровая картинка, несущая правило или данные** (схема, скриншот с условиями, таблица картинкой) — файл в комплект не переносится; содержание переписывается текстом по подтверждению аналитика, иначе в матрице строка долга вида «правило на изображении» с ID карточки (виды долгов — `_meta/templates/docs-readme.md`, таблица видов; порядок — `_meta/templates/screen-form.md`, раздел «Изображения источника»). Содержание картинки не выдумывается. Декоративная иконка не переносится и не помечается. В карточке картинка перечисляется в разделе «Изображения источника». Отсутствие и раздела, и долга — класс «незарегистрированный долг», линия 4, исполнитель (раздел) + координатор (строка матрицы).
3. **Файл-вложение (Visio у fun-sys-15, XSD, DOCX)** — переносится файлом байт-в-байт в `files/` рядом с карточкой-владельцем и учитывается блоком «Приложенные артефакты» с происхождением (page_id, срез) — `_meta/templates/attachments-block.md`. Файл без ссылки из карточки — сирота, гейт даёт ✗. Если файла в выгрузке нет — долг «правило на изображении» так же.

Для fixlist G4: строки по fun-sys-05/06/07/15 получают решение по этим трём правилам, без отдельного OQ; дословность диаграмм проверяется ревьюером тем же протоколом (mermaid-текст — литерал). Срез источников называем «срез», не «канон».
