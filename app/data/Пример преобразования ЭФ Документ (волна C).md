### EV-1. Открытие формы

**Шаг №1.** Осуществляется формирование массивов <Доступные счета для
создания> и <Доступные счета для редактирования> — получение счетов на
основании «[РРКО_ИПИ] Рабочие переменные».<Доступные пользователю счета>.

**Массив <Доступные счета для создания>:**
[ENT-001 Инкассовое поручение исходящее](../../data-model/ent-001-outgoing-collection-order.md).<ID «Счет клиента»>
входит в выборку из «[РРКО_ИПИ] Рабочие переменные».<Доступные
пользователю счета>, для которой выполняется условие:

- В связанном массиве <Доступы к счету для платежных документов> есть
  элемент, где:
  - <Тип документа> = РКО_ИПИ;
  - и в связанном массиве <Разрешения для документа> есть элемент, где:
    - <Тип действия над документом> = "ACTION_CLIENT_USER_CREATE";
    - и <Признак доступа> = 1.

**Массив <Доступные счета для редактирования>:**
[ENT-001 Инкассовое поручение исходящее](../../data-model/ent-001-outgoing-collection-order.md).<ID «Счет клиента»>
входит в выборку из «[РРКО_ИПИ] Рабочие переменные».<Доступные
пользователю счета>, для которой выполняется условие:

- В связанном массиве <Доступы к счету для платежных документов> есть
  элемент, где:
  - <Тип документа> = РКО_ИПИ;
  - и в связанном массиве <Разрешения для документа> есть элемент, где:
    - <Тип действия над документом> = "ACTION_CLIENT_USER_EDIT";
    - и <Признак доступа> = 1.

**Шаг №2.** На основании исходящих параметров функций, с которых была
вызвана форма, заполняются значения переменных и соответствующих
элементов формы.

- **Видимость:** всегда
- **При нажатии** на слово «К списку инкассовых поручений»:
  1. Вызов функции формы [FF-1 «Сохранить документ»](#ff-1-сохранить-документ).

     **то** отображается сообщение MSG-2.
  3. ЭФ «… поручение» закрывается, переход к
     [SCR-CL-01 «Журнал документов»](../scr-cl-01-document-journal/README.md).

## Находки стресс-теста словаря (для ревью канона)

- **Н-1. Атрибут «Заголовок:»** — отображаемый лейбл поля/блока, в т.ч.
  вычисляемый («Ошибки»/«Предупреждения»; «← К списку…»). В словаре нет
  подходящего ярлыка (не Формат — это не маска, не Подсказка). Кандидат в
  закрытый реестр ДОПОЛНИТЕЛЬНЫХ атрибутов: **Заголовок:**.
- **Н-2. «Обновление: При Сохранении, Отправке, Подписании»** — момент
  пересчёта; по правилу словаря момент — шаги событий/кнопок, в FLD
  осталось только правило. Ложится штатно, находка подтверждает границу.
- **Н-3. Иконки-состояния кнопки B-9** (`<img>` раскрыто/свёрнуто) —
  переносится словами, изображения — нет (правило «Что не переносится»).
- **Н-4. «Функции формы»** источника — не поведение ЭФ, а функции;
  уходят в FUN-карточки (правило «Сохранение данных формы» уже покрывает).
- **Н-5. Строки «См. п. …» / «[ПЭД] …»** — страницы вне выгрузки: перенос
  невозможен, отсылка + открытый вопрос (тема волны D «отсылка ≠ перенос»).
- **Н-8 (ревизия 2026-08-17). «Функции формы» остаются в карточке ЭФ
  именованными наборами шагов.** Категория шаблоном не покрыта — риск
  молчаливой потери (экзаменационная карточка сохранила их стихийным
  нешаблонным разделом). Рассмотрены и ОТКЛОНЕНЫ: (а) вынос в карточки
  FUN — требует выдумывания входных сигнатур (в источнике их нет —
  суррогат) и отрывает шаги от контекста полей ЭФ, с которыми они
  работают напрямую; (б) инлайн в тело каждой кнопки — «Сохранить
  документ» вызывается из пяти мест, дублирование ×5 = лавинный дифф.
  Правило: раздел «Функции формы» легализуется в шаблоне — именованные
  повторно используемые наборы шагов формы (расширение существующего
  правила «повторно используемый набор шагов описывается один раз»),
  внутренний ID `FF-N` (класс FLD/EV/B/MSG), шаги дословно с маркерами
  источника; кнопки и другие наборы ссылаются якорем [FF-N «…»](#…);
  упоминание словами без ссылки — дефект. Таблица маппинга параметров
  вызова остаётся при шаге вызова (правило «вызовы не сворачиваются»).
  Самостоятельными функциями FUN они не являются и в реестр функций не
  попадают.
- **Н-7. Семантика `%зачёркнуто%` — инверсия смысла в боевой карточке.**
  `%зачёркнуто%` — ПОСТФИКСНЫЙ маркер выгрузки: зачёркнут предыдущий
  текст (прецеденты: «Наименование клиента %зачёркнуто%» в контролях,
  «= "EXPORT_TO_ABS_ERROR" %зачёркнуто%» в ЭФ Банка). На этой странице
  зачёркнуто утверждение «Шаг № 3 исключается», а описание вызова метода
  «Светофор» — живой текст: шаг 3 ВЫПОЛНЯЕТСЯ. Экзаменационная карточка
  scr-cl-02 (README, EV-1 шаг 3) несёт ровно обратный смысл («шаг
  исключён, вызов не выполняется») — слабая LLM ошиблась так же, сверка
  не поймала. Нужны: (а) правило канона о семантике `%зачёркнуто%`
  (рядом с правилом «<s> — перенос с пометкой „Неактуален"», волна D);
  (б) исправление scr-cl-02 в контрольном дозаходе; (в) кандидат-сторож:
  `%зачёркнуто%` в чистовике = брак (маркер выгрузки, не перенесённая
  нотация).
- **Н-6. «Вкладки» ≠ «части».** Источник о вкладках UI не говорит —
  описание разнесено по дочерним страницам («Документ → реквизиты»);
  шаблон же знает только «экран с вкладками». Термин раздела и правила
  шаблона стоит обобщить до «частей экрана» (вкладки — частный случай),
  чтобы структура папки не приписывала форме несуществующие вкладки.
