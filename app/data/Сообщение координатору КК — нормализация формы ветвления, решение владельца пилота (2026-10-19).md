# Координатору КК: нормализация формы ветвления — решение владельца пилота

Дата: 2026-10-19, ночь. От владельца канона. Продолжение замечания от 19.10 (раздел 2, «Волна 5
стандарта»): там было «до отдельного сообщения ничего не делать» — это то самое сообщение.

## Решение

1. **Механическую часть делаем сейчас**, одним MR при ближайшем заходе команды, после приёма
   среза канона: утилита `normalize_tables.py --branch-form` переписывает ячейки таблиц, где
   ветвление записано в одну строку, в форму стандарта (условие и каждый исход — со своей
   строки через `<br>`; слова «то» / «иначе» открывают строку). Содержание не меняется: текст
   условий, значения, литералы и порядок исходов остаются как были, меняются только переносы.
   На копии комплекта 19.10 это 297 мест в 50 файлах.
2. **Запускает команда сама** в своём клоне — утилита лежит в каноне (`_meta/tools`), отдельной
   подготовки не нужно.
3. **Остаток руками — только при касании карточки.** Места, которые утилита не берёт
   (ветвления в маркерах списков, вложенные условия; по комплекту около 1070), приводятся к
   нотации §1 стандарта тогда, когда карточка правится по другой причине. До того
   предупреждения прибора «форма ветвления — «то»/«иначе» не в начале строки» остаются как
   напоминание; на вердикт комплекта они не влияют.

## Порядок одним MR

Предварительно: срез канона `d8feaae` принят (`accept_canon`, baseline), MR по матрице
(колонка «Уведомления», перенос приложения 4) — отдельно и раньше, чтобы не смешивать.

1. Сухой прогон — посмотреть, что изменится (ничего не пишет):

   ```
   python <канон>\_meta\tools\normalize_tables.py --branch-form docs
   ```

   Ожидание: перечень файлов с числом переносов и итоговая строка «форма ветвления в ячейках:
   файлов N из M, переносов K; пропущено (вручную): маркер списка в ячейке ×…». Пропущенное —
   это как раз остаток п.3, его не трогаем.

2. Запись:

   ```
   python <канон>\_meta\tools\normalize_tables.py --branch-form --write docs
   ```

3. Самопроверка комплекта обычным порядком. Ожидание: вердикт тот же, число предупреждений
   «форма ветвления» уменьшилось на K, новых ✗ нет (сверка литералов и ячеек с источником
   подтверждает, что содержание на месте).

4. MR в `master` с названием «Нормализация формы ветвления в ячейках таблиц (notation §1), без
   изменения содержания» и строкой самопроверки в описании.

Пример «до / после» на карточке `fun-cl-01-save-request.md`: в ячейке «**Если** условие,
**то**<br>= TRUE<br>**Иначе,**<br>= FALSE» слово «то» уходит на свою строку —
«**Если** условие,<br>**то**<br>= TRUE<br>**Иначе,**<br>= FALSE». Остальные случаи в комплекте
того же вида.
