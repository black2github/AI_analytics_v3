## Сторожа

### T1. Таблица источника целиком не найдена (ЗК-04, К1)

Дом: `normalize_tables.check_source_tables` (строка ~2840). Сейчас ячейки-ссылки на Confluence
(`url_cells`) и ячейки-изображения полнотой не считаются, и таблица, состоящая только из них,
не проверяется вовсе (пример команды: таблица «Макеты ЭФ» — размерности xl/l/m/s/xs со
ссылками, не перенесена, прибор молчит).

Правило: для каждой таблицы источника, у которой **ни одно** значение не вошло в дословную
сверку (все ячейки — ссылки, изображения, пусто), проверить **заголовки** таблицы и ключевые
ячейки первой колонки (текст без ссылок/картинок, ≥ 2 символов) по карточке **и по README группы
карточки** (для ЭФ ссылки макетов живут в README группы — шаблон `screen-form.md:29, 54`); не
найдено ни одного → `⚠ таблица источника «<заголовки>» (<N> строк): дословных значений нет
(ссылки/изображения), заголовки в карточке и README не найдены — таблица не перенесена? (макеты
ЭФ — README группы; правило на изображении — долг)`. Найдена хотя бы часть → i-строка «таблица
без дословных значений — перенос проверить приёмкой» (как сейчас для `img_mixed`).
НЕсрабатывание: таблица, чьи заголовки есть в README группы; таблица с обычными значениями.

### T2. Изображения источника без следа в карточке (ЗК-04, К1)

Дом: там же, рядом с подсчётом `<img` (строка ~2917) или отдельной функцией в сверке карточки с
источником. Считать `<img`/`![` по странице источника; в карточке искать любой из следов: раздел
«Приложения» (блок приложений, `attachments-block.md`), ссылки на `files/`, долг «правило на
изображении» (в матрице или `open-questions.md` — достаточно текста «правило на изображении» в
карточке/матрице с FROM-ID карточки). N > 0 и следа нет → `⚠ изображения источника ×N: в карточке
нет ни блока приложений, ни files/, ни долга «правило на изображении» — проверить приёмкой
(изображения не переносятся, правила на них — долг)`. НЕсрабатывание: страница без картинок;
карточка с блоком приложений; карточка с долгом.

### T3. Перечень таблиц источника для приёмки (ЗК-04, i)

В отчёт сверки карточки с источником — одна i-строка: `i таблицы источника: N — «<заголовок>»
(<строк>); …` (первые 3 заголовка полностью, остальное счётчиком). Это подсказка акцептующему для
потерь, которые механически не ловятся (пример: кнопка браузера «Обновить» из таблицы «Описание
кнопок Браузера» в одну строку — текст есть в карточке в другой роли). Тест: строка есть при
наличии таблиц, отсутствует без них.

### T4. Одинаковые названия у разных ID одного типа — по «Реестру ID» матрицы (ЗК-25, К3)

Дом: `kitcheck/checks/matrix.py`, рядом с `check_registry_duplicates` (дубль ID — ✗, не трогать).
Пример команды: `CTL-015` (`cards-org.md`) и `CTL-034` (`cards-applicant.md`) с одним названием —
суб-ID внутри файлов групп, title шапки у них нет, поэтому `title_uniqueness` (по frontmatter)
их не видит. «Реестр ID» матрицы несёт названия всех ID (собирает `matrix_sync` из заголовков):
группировать строки реестра по (тип по префиксу ID, нормализованное название — регистр,
пробелы, ё/е, как в `_norm_title`), ≥ 2 разных ID → `⚠ одинаковые названия разных ID одного типа
(реестр матрицы): CTL-015, CTL-034 — «…»`. Не дубль: части одной группы с общим базовым ID
(`SCR-CL-01.1…`, как в `check_title_uniqueness`), README-реестры (`*-000`). Чтобы не дублировать
⚠ с `title_uniqueness`, пары, уже найденные по title шапки, не повторять (или объединить два
сторожа в один отчёт — на усмотрение, лишь бы пара из примера команды была видна ровно один раз).

### T5. Долг «требуется заход» с признаком чужой цели (ЗК-10, ЗК-11, К2)

Дом: `link_debts.py` (разбор строк долга, `_OWNER_RE` строка 58, коды каталога `catalog_codes`
строка ~331). Факт команды: до ревью чужие данные (ОНБ_2021, «Справочник городов», «Подразделение
Банка», «АС ППБ_СИП …») — девять долгов «нет целевого артефакта data-model «…» — требуется заход
create-data-model», чужие методы — восемь долгов «… internal-contract «…» — требуется заход
create-internal-contracts». Формула «у владельца» не применялась вовсе.

Правило: долг формы «требуется заход create-data-model» или «create-internal-contracts» (без
«у владельца») → ⚠, если в имени цели есть (без учёта регистра): код `code`, ключ `key` или
значимое слово названия другого сервиса из `_meta/services.json` (слова короче 4 символов и
общие — «сервис», «система», «банк» — не считать); либо для data-model — слова «справочник»,
«подразделение», «классификатор», «АС », «внешн». Текст: `⚠ долг <FROM-ID> «<имя>» — похоже
на чужую цель (<признак>): данные/метод другого сервиса — формула «у владельца <service-id>»,
справочник платформы — EXT в dictionaries.md, внешняя АС — карточка вызова (create-artifact,
правило долга)`. НЕсрабатывание: долг с «у владельца»; долг на собственную сущность без
признаков; имя с коротким совпадением («банк»).
