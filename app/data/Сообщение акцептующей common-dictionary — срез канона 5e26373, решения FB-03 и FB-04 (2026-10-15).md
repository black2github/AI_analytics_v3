## Что сделать

### 1. Принять срез канона

Из каталога репозитория сервиса, при клоне канона на `master` после `git pull`:

```powershell
git -C <путь к клону канона docs-o2new> pull --ff-only
```

Ожидается `master` на `5e26373` (или новее).

```powershell
cd <путь к src-common-dictionary>; python <путь к клону канона docs-o2new>\_meta\tools\accept_canon.py --profile README.md
```

Ожидается строка `✓ срез канона: fec9eb5 → 5e26373; профиль закоммичен` и три строки `✓ SF-0N`.
Утилита сама коммитит профиль; push делает команда.

### 2. Перепрогнать гейт переноса по УЛ

Той же командой, что в `sandbox/authorized-person/transfer-gate-retry-1.md`, с ключом `--sources`.
Ожидается: в строке CORE-20 «открытые вопросы» — `✓ открытых вопросов без долга нет
(open-questions.md)` вместо «журнал не найден»; итог READY. Отчёт положить рядом с прежними.

### 3. Закрыть записи в журнале

В `coordination-log.md` — запись «решение акцептующего»: срез `5e26373` принят, FB-03 и FB-04
закрыты решениями владельца канона, гейт УЛ перепрогнан (строка ИТОГ дословно).
