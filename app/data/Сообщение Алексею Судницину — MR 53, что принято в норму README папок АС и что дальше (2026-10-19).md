# Алексею Судницину: MR !53 — что из него вошло в норму README папок внешних АС и что дальше

Дата: 2026-10-19. От владельца канона. По MR !53 «Добавлены README обзора интеграций в папках
внешних АС» в `EAN/docs-external-contracts`.

## Что произошло

MR !53 поднял вопрос, который канон не закрывал: уровень папки внешней АС. Вместо правки MR
вопрос решён нормой (канон, шаблон `contract-call.md` раздел A; техбук `repo-topology.md` §9,
`conventions.md` §5.1.1) и утилитой `extint_registry.py`, которая собирает реестры. По норме
переведён весь репозиторий: MR `extint/as-readme-registry` (ветка от trunk 9367154, три
коммита) ждёт одобрения владельца кода.

| Выравнивание таблиц | да, утилита пишет таблицы выровненными |

## Что не принято и почему

- **Колонка «Потребители (service-id)» в таблице методов.** Потребители живут в разделе
  «Потребители» каждой карточки, там их проверяет утилита (три колонки, адрес на `HEAD`).
  Вторая копия в README разошлась бы с первой, как расходилась сводка потребителей в
  корневом README (снята тем же MR).
- **`title` у 22 карточек.** В !53 они равны H1 карточек, а по шаблону `title` — дословный
  заголовок страницы-источника. Вместо копии H1 реестр показывает H1 сам, а ⚠ «нет title»
  остаётся владельцам карточек, которые знают страницу.
