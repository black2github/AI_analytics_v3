## Задача 6. Сторож состава шапки по типу документа (волна 6, ПР-04, ЗК-26)

- Норма: техбук `conventions.md` §5, yaml-схема шапки и пункт «Состав полей шапки — закрытый по
  типу документа»: общие `id`, `type`, `service` (+ `title`, `confluence_page_ids` в reverse);
  `kind` — только `function`; `entity` — только `control` (файлы карточек); `partOf` — файл-часть
  многофайлового документа (карточки контролей, части группы ЭФ); `origin` — только документы
  BRD (`feature`, `use-case`, `business-rules`, `vision`), у `nfr` его нет; `version` — не
  используется в новых комплектах (⚠ «поле устарело»); любое иное поле, включая `status`, — вне
  схемы.
- Где: `selfcheck.py`, проверка уровня файла рядом с существующей проверкой frontmatter
  (`id`/`type`/`service`); частям с `partOf` без `id` — не требовать `id`.
- Что печатать: `⚠ <файл>: поле шапки вне схемы типа <type>: <поле>` (одна строка на файл,
  поля перечислены); отдельная сводная строка в конце: число файлов с отклонениями по полям.
  Вердикт не меняется.
- Тесты (`tests/test_selfcheck_frontmatter_schema.py`): законные поля по типу — тишина;
  `kind` у `screen-form` — ⚠; `status` — ⚠; `origin` у `feature` — тишина; `partOf`-часть без
  `id` — тишина.
- Живые прогоны: КК, lk-mp, common-dictionary УЛ — число ⚠ по полям в сдаче (ожидаю заметное
  число `version` у старых комплектов — это нормально).
- Канон: копия; ветка `meta/frontmatter-schema-guard`.

## Задача 13. matrix_sync --write: отказ по тексту без ID в выводимой ячейке (добавлена 2026-10-18)

Решение владельца пилота 18.10 (норма «матрица производна от тел» принята; долги — ручной раздел,
переносится байт в байт). Пробел: отказ `--write` считает потерей только ID (`cell_ids`), а
свободный текст без ID в ячейке покрытия или источников — пометка вида «— (долг L835)»,
«см. OQ-158», «заглушка» — при пересборке заменяется на «—» молча. По асимметрии ошибок это
отказ, не предупреждение.

- Где: `matrix_sync.py`, сбор отказов в `--write` рядом с «ID ячеек, которые пересборка
  потеряет»; `--check` печатает то же как ⚠.
- Правило: ячейка выводимой колонки (покрытие функций, покрытие процессов, «Целевые
  артефакты» источников) после удаления ID, диапазонов, разделителей `, ;` и «—» непуста →
  отказ: `«<раздел>»: текст без ID в выводимой ячейке ×N: <строка> / <колонка>: «<текст>» —
  перенесите в ручной раздел («Долги по ссылкам», приложение) или снимите`. Колонка
  «Название» и ручные разделы не проверяются; «Основание» источников — ручная колонка по
  шапке утилиты, не трогать.
- Тесты (`tests/test_matrix_sync.py` или рядом): срабатывание — пометка в ячейке покрытия →
  код 2, файл не тронут; пометка в «Целевые артефакты» → код 2; НЕсрабатывание — ячейка из ID,
  диапазона «A … B», «—» и пустая → отказа нет; текст в «Название» → отказа нет.
- Эталон 43 отчётов: отличия только в отчётах `*__matrix_sync` тех комплектов, где такие
  ячейки есть (новое ⚠ «текст без ID»), перечислить с числами; остальные отчёты — без
  отличий (поправка параллельной сессии 18.10). Живой прогон `--check` по КК, lk-mp,
  common-dictionary УЛ, стенду, эталону — число ячеек с текстом в сдаче.
- Канон: копия, ветка `meta/matrix-sync-text-cells`. Сделать ДО перевода первого действующего
  комплекта на шаблон (эталон в их числе).
