## Команды владельцу

1. Добавить в индекс README этого шага:

```powershell
git -C C:\tmp\extc-trunk add -- '*README.md'
```

2. Проверить индекс:

```powershell
git -C C:\tmp\extc-trunk diff --cached --stat
```

Ожидается 27 файлов: 21 новый README, `README.md`, `crypto-module/README.md`, два README каналов,
`fns-my-signature/README.md`, `gpb-smev/README.md`. Других изменений в рабочем дереве нет.

3. Закоммитить:

```powershell
git -C C:\tmp\extc-trunk commit -F C:\tmp\extc-s3-commit.txt
```

4. Отправить ветку:

```powershell
git -C C:\tmp\extc-trunk push -u origin extint/as-readme-registry
```

После push — MR в `trunk`. Если до вливания войдут !37, !44 или !57, скажите: сделаю ребейз и
повторю `--write` / `--check`.
