# Аудит качества комплекта `_meta` (docs-o2new)

Дата: 2026-08-02. Метод: три независимых LLM-аудитора (шаблоны / скиллы / правила,
каждая находка с файл:строка и цитатой) + детерминированные механические проверки
(скрипт целостности ссылок, грепы дублирования). Предпосылка: правки notation.md
(ветка meta/notation) считаются внесёнными; находки, уже учтённые в реестре
Д-1…Д-16, исключены — кроме случаев, где аудит нашёл их новые грани.

Статус верификации: классы А-1, А-9 подтверждены скриптом (детерминированно);
остальные — аудиторами с цитатами, выборочно перепроверены; **перед волной правок
каждую находку сверить с файлом** (правило «числа из прогонов»).

Критерий приоритета: (1) ломает исполнение скилла буквально или ведёт к молчаливому
искажению данных → (2) широта поражения на пилоте → (3) цена починки
(механическая дешевле решения).

## Замечание метода

Половина находок П1-уровня (А-1, А-2, А-3, А-18, частично А-9) — ровно те, что
структурный линтер (Д-13) ловил бы механически: битые ссылки, несуществующие пути,
неработающие грепы. Аудит фактически исполнил роль линтера вручную — это самый
сильный практический аргумент в пользу Д-13 после MR по нотации.

Полные списки находок с цитатами — в отчётах трёх аудиторов (зафиксированы в
сессии 2026-08-02); данный файл — синтез с дедупликацией. Перед правкой каждого
места — сверка с файлом обязательна.
