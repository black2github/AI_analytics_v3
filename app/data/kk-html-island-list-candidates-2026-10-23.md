# Кандидаты на перевыгрузку 1.9.8: списки в ячейках HTML-островов без маркеров

Срез архива: `EAS/src-business-cards`, `sources/raw`, коммит `717b11f`; подсчёт 2026-10-23.

**Дефект.** До версии 1.9.8 экспортёр не ставил маркеры CriticMarkup на цветные пункты
списков `<ol>`/`<ul>` внутри ячеек вложенных таблиц (HTML-островов); абзацы `<p>` той же
ячейки маркеры получали. После `reject-all` текст таких пунктов оставался в ПРОМ-срезе,
после `apply` задачи не появлялся как новое.

**Метод подсчёта.** По markdown архива: берётся каждая самая внутренняя ячейка (`<td>`/`<th>`
без вложенной таблицы), в которой есть хотя бы один `<span class="critic-ins|critic-del">`
И хотя бы один непустой пункт `<li>` без такого span внутри. Страница попадает в список,
если таких пунктов хотя бы один; «пунктов» — их число на странице; «задачи» — задачи
маркеров в этих ячейках.

**Оговорка.** Это кандидаты, НЕ подтверждённые: по markdown нельзя отличить цветной пункт,
маркер которого потерял экспортёр, от чёрного пункта рядом с цветным абзацем. Подтверждённый
список даст перевыгрузка этих страниц версией 1.9.8 и сравнение с архивом
(`run-pick.bat <новая выгрузка> <архив> --pages ids.txt --dry-run`: страницы «заменена»
с причиной «только разметка маркеров»).
