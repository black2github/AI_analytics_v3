# Координатору комплекта КК: ISS-03-R2 пересобирать на срезе 0e32b01; правило приёмки по категориям дельты

Дата: 2026-10-25. От владельца канона. Дополняет сообщение 24.10 «Полная перевыгрузка архива экспортёром 1.9.13».

## 1. ISS-03-R2 — следующую пересборку делать из среза 0e32b01

По журналу продукт P12 (ревью r10) собран на срезе источника 717b11f. Дальше на 717b11f не итерировать:
следующий прогон исполнителя — тем же накопленным промптом, но с источником `sources/confluence` на
0e32b01. Промпт от среза не зависит, правки десяти раундов ревью в нём сохраняются; приёмка захода
будет одна, вместо приёмки P12 и отдельного дельта-захода на новый срез.

Дельта среза по страницам захода (717b11f → 0e32b01): главная ЭФ создания/редактирования и
«Подтверждение» — «изменён текст»; «в режиме просмотра» — «дополнен текст» (восстановленные
экспортёром строки, не правка аналитика); «Документы и вложения», «Ввод адреса», «Согласие №2» —
только разметка, ПРОМ-текст тот же. В сдаче захода строка «Срез источника» — 0e32b01.

## 2. Правило приёмки по категориям дельты (действует для всех дозаходов по срезу 0e32b01)

Категория берётся из приложения к сообщению 24.10 (вердикт утилиты переноса по странице-источнику):

| Категория страницы-источника | Что делать с карточкой | Кто принимает |
|---|---|---|
| только разметка маркеров | ничего; прибор подтверждает, что дифф ПРОМ-среза по странице пуст | никто |
| дополнен текст | исполнитель дописывает восстановленные строки таблиц и пункты списков; снятий в этой категории нет | прибор: selfcheck и гейт формы; человек не читает |
| изменён текст | дозаход в режиме изменения по диффу ПРОМ-среза; после захода — ревьюер | акцептующий: контроли и модели данных целиком, остальные типы — по выборке из замечаний ревьюера |

Если у карточки несколько страниц-источников, действует самая строгая категория из них.
Правило записывается нормой канона; до записи применять по этому сообщению.

## 3. До завершения плана миграции ПРОМ-среза

Экспортёр по дереву КК не запускается, новые задачи в ПРОМ не вводятся: срез 0e32b01 — единственная
точка отсчёта дельты. Задачи, завершённые за это время, вводятся сразу после завершения плана обычным
порядком (перевыгрузка страниц задачи → apply → тег → дельта-заход).
