АС ЕСК (ЦФТ ГО) — единая система клиентов банка: клиентские данные и их актуальность,
полномочия на подпись, заявки 115, регистрация продуктов ЦР, сообщения «ИО Клиент».

## Шапка карточки, которую читает утилита

```yaml
---
id: EXTINT-ESK-001
title: 'Запрос на создание заявки 115 в АС ЕСК'
type: external-integration
kind: operation          # operation | format
channel: suv             # suv | online-adapter | rest | mq | file | kafka | postmessage — перечень закрывается после первого прохода
sync: async              # sync | async; у kind: format не указывается
confluence_page_ids: [2184432904]
---
```

Отображение `channel` в README — по словарю шаблона (`suv` → «СУВ», `online-adapter` →
«онлайн-адаптер», `rest` → «REST», `mq` → «MQ», `file` → «файл», `kafka` → «Kafka/СИП»,
`postmessage` → «PostMessage»). Порядок строк: по каналу в порядке словаря, внутри канала по
номеру. Карточка без `title`, `kind` или `channel` — ⚠ утилиты; строка в реестре остаётся (ничего
не теряется), «Название» = «—» (реестр берёт только `title`, Д-44), без `kind` — в «Операции»,
канал «—».
