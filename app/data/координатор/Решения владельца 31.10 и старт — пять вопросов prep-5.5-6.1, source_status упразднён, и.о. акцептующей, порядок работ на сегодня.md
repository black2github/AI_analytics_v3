## Решения по пяти вопросам prep §6

1. **`source_status` в frontmatter упраздняется.** Поле было флагом старой выгрузки без CriticMarkup («draft» = страница выгружена со всеми требованиями без разбора, «active» = только с подтверждёнными). Сейчас полная картина читается из `sources/raw` с разметкой задач, а поле только вводит в заблуждение. Действия: исполнитель снимает `source_status` из frontmatter всех карточек, где оно есть (48 файлов, `grep -rl "^source_status:" docs`), одним заходом внутри волны L1 или отдельным мини-заходом; строки fixlist «утрачен source_status: draft» и «source_status active при draft» — закрыть статусом «снято: поле упразднено решением владельца 31.10»; первую строку OQ-376 дополнить: «source_status упразднён 31.10, восстанавливать не нужно, поле снимается»; 21 предупреждение selfcheck «поле вне схемы» уйдёт само. Канон не меняется (схема поля и так не знала).
2. **CALL-EXT-032/033/034 (GBO-92191) легитимны.** Страницы разморожены 05.10 (матрица L1777, сверка 09.10), карточки введены заходом PROM-5.7 по постановке владельца. Абзац в `external/README.md` оставить, слова «подтверждение владельца в prep-5.5-6.1 §6» заменить на «подтверждено владельцем канона 31.10»; строки fixlist G6 по ним — «снято: подтверждено».
3. **Figma-URL (scr-cl-16/17/18) и диаграммы/картинки (fun-sys-05/06/07/15).** Живые ссылки не переносятся: название текстом и долг с ID карточки (прецедент OQ-203). Диаграммы по существующей норме: mermaid-текст источника дословно блоком кода (прецедент OQ-287), растр с правилом — текст по подтверждению аналитика либо долг «правило на изображении» и раздел «Изображения источника», Visio — файл в `files/` по блоку вложений. Полный текст — файл владельца «Диаграммы и картинки источников в function-system — ответ координатору КК по линии G4» (30.10). Новых OQ не заводить.
4. **mod-widgets-rtl-003.** Владелец виджета — подразделение Розницы, но развитие виджета ведёт команда КК (так сделано намеренно, чтобы не включать Экосистему в контур PCI DSS: виджет работает на устройстве пользователя и получает чувствительные данные карт вне каналов Экосистемы). Содержание карточки — ответственность команды КК; пометка «вводится задачей» не нужна. Строка fixlist — «снято: решение владельца 31.10», долг владельцу widgets не заводить.
5. **OQ-377** — правильная форма аддендума к OQ-99 (реестр append-only, старый текст не правится). Закрыть первой строкой: «- Статус: зафиксировано (аддендум к OQ-99: изображения img/03249f87.png и img/a7051b55.png в выгрузке есть; формулировка OQ-99 не правится)». Не ждать 5.5.
