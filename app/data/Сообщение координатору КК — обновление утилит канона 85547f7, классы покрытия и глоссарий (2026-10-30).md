# Сообщение координатору КК — обновление утилит канона (master 85547f7 и c37eb63, 2026-10-30)

Дополнение к сводному сообщению по состоянию master 4d09481 (пункт «что ещё придёт»). Действий от команды не требует, кроме обновления клона канона перед следующим прогоном.

---

Коллеги, утилиты канона обновлены двумя вливаниями (master канона 85547f7 и c37eb63), обновите клон перед прогонами:

```
git -C <клон канона> pull --ff-only
```

Что изменилось:

- `source_coverage.py`: в сводке два новых класса. «Снято с миграции» — страницы с пометкой DELETE или [DRAFT] в заголовке либо словами «снято с миграции»/«черновик» в основании или целевом типе описи (на КК их 8; раньше они считались справочными, справочных стало 20). «Каталоги-узлы без собственной страницы» — каталоги выгрузки, у которых есть дочерние страницы, но нет своей (на КК 49; раньше печатались как «нарушение инварианта имён выгрузки»); дефектом выгрузки теперь считается только пустой каталог без страницы и без детей, на КК таких нет. Число пробелов миграции не изменилось (16), перечень тот же, `--strict` ведёт себя как раньше.
- `selfcheck.py` (сторожа в `normalize_tables.py`): для документов `type: glossary` не применяются сторож полноты кавычечных литералов источника и сторож выносок «>» (выноска-делегирование предписана шаблоном глоссария); под файлом печатается информационная строка «сторож литералов не применяется к глоссарию». Для `type: domain-vision` снят только сторож литералов. Итог selfcheck на КК не изменился: 388 файлов, ✓360 ✗2 ⚠26 (два ✗ — карточки команды fun-cl-54 и fun-cl-33).
- Словарь классов непокрытия в `_meta/migration/prompt-plan.md` дополнен словами новых классов: в описи «снятое» называйте этими словами, а не reference-only.

- Второе вливание (c37eb63) — внутренняя перестройка прибора без изменения поведения: проверки карточки вынесены из `normalize_tables.py` в пакет `kitcheck/checks/card_*.py`, в `normalize_tables.py` остался нормализатор таблиц. Команды, которыми вы пользуетесь (`selfcheck.py`, `normalize_tables.py --check`, `normalize_tables.py --branch-form`, `link_debts.py`, `transfer_gate.py`, `source_coverage.py`), ключи, отчёты и коды возврата те же; на КК (master 4d09481) и эталонном комплекте сверено: отчёты совпадают строка в строку. Если у вас есть собственные скрипты, импортирующие функции проверок из `normalize_tables`, старые имена пока работают через переадресацию, но на один релиз: переведите их на `kitcheck.checks`.
