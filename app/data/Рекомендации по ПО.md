# Рекомендации по LLM

1. **Claude code от antrophic** - это самодостаточное приложение, где доступны разные LLM от antropic - нужна подписка.
2. **Codex от ChatGPT** - требуется платная подписка. Рекомендовано Максимом Коробейниковым. 
3. **Cursor** - содержит встроенные LLM от разных производителей (точнее, доступ к ним, и пока без VPN), к сильным LLM доступ предоставляется по API - поэтому использование обходится существенно дороже, чем по подписке. То есть можно подключить и LLM на которые есть подписка. Сам Cursor какое-то время работает бесплатно, потом - платная подписка.
4. **VS Code** - Cursor на минималках. Подписки не требует. Можно так же подключать любые LLM (в рамках подписок к LLM, разумеется).
