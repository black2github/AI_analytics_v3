# Постановка: сторож «приписка источнику» обратного направления в гейте карточек контролей (FB-12 КК)

Дата: 2026-10-29. Для сессии «Правки прибора, акцепт и рутина». Коммит analyzer — по слову владельца, `git add -- <перечень>`;
срез в канон (`_meta/tools`) и бандл — после приёмки владельцем, отдельным шагом. Основание: замер «Замер FB-12 —
приписка источнику в карточках контролей, два комплекта (2026-10-29)» и решения владельца 29.10 (записаны в FB-12 КК,
дополнение «2026-10-29, вечер», и в статусе analyzer). Норма объединённой ячейки уже в каноне: master `c722361`
(`_meta/templates/controls.md` — поле «Сообщение об ошибке» и чек-лист п. 6; `_meta/skills/review-artifact.md`).

## Решение владельца, которое реализуется

Ввести ⚠ (вердикт не меняет) **обратного направления**: карточка контроля задаёт текст сообщения, а ячейка сообщения
однозначно сопоставленной строки источника пуста. На двух комплектах — 0 ложных из 410 сопоставленных карточек,
1 истинное срабатывание (КК CTL-052). Текстовый детектор по фразам **не вводится** (34 срабатывания, 0 приписок).
По асимметрии ошибок пропуск подстановки сообщения из соседней строки хуже лишнего ⚠.

## Где в приборе

Дом — гейт `app/scripts/CI/normalize_tables.py`, рядом с `_fc_fabricated_attributes` (строка ~4799, регистрация
`Check("fabricated_attributes", …, scope="file")` ~5269): это тот же класс «односторонняя сверка приписку не видит»,
у проверки уже есть `fx.text` карточного файла и `fx.source_text`. Проверить при постановке: что именно лежит в
`source_text` для файла карточек `cards-*.md` с несколькими `confluence_page_ids` (одна страница / конкатенация /
`None`); если страниц несколько — сопоставление вести по всем страницам файла. Вариант «в kitcheck» (selfcheck
комплекта) не брать: там нет текста источника по карточке.

## Условия срабатывания ⚠ (все четыре, иначе молчать)

1. У файла карточек есть страница источника (`confluence_page_ids` / `source_text`), и на ней есть таблица с
   колонкой сообщения из словаря заголовков (словарь и правило «заголовок целиком, допускается точка в конце и хвост
   «(атрибут error.message)»» — из отчёта замера, раздел «Инвентаризация колонок»; интеграционные «Структура
   сообщения», «XML структура сообщения», «Пример сообщения» и т. п. колонкой сообщения не считаются).
2. Строка источника найдена **однозначно**: сначала по реквизиту и названию проверки из заголовка карточки
   «Реквизит: Название», затем по тексту «Логики проверки» (+ «Условие выполнения») с нормализацией из отчёта и
   порогом подобия 0,9 при единственном кандидате. Несколько равных кандидатов с разной заполненностью ячейки →
   не сопоставлено, молчать.
3. Ячейка сообщения строки пуста (пустой `<td>`, прочерк) и **не объединена**: не `colspan`/`rowspan` и не хвост
   объединения; строка-раздел шапки на всю ширину — не строка данных.
4. Поле карточки «Сообщение об ошибке» заполнено содержательно: не «в постановке не задано» и не
   «в постановке не задано: ячейка объединена с логикой проверки».

Текст ⚠: `предупреждение: CTL-NNN — поле «Сообщение об ошибке» задано («…» — первые 60 знаков), а ячейка сообщения
строки источника «<реквизит: название>» на странице <id> пуста — текст не из источника (приписка; правило шаблона:
ровно «в постановке не задано»)`.

Строка «сверка не выполнена»: если у файла карточек страница не указана или таблицы с колонкой сообщения на ней
нет — **одна** информационная строка `i` на файл (не на карточку), в сводке selfcheck комплекта — одна строка на
комплект с числом файлов; шума на эталоне (53 карточки без `confluence_page_ids`) быть не должно.

## Тесты (обязательно, с тестами на НЕсрабатывание)

Срабатывание:
- пустая ячейка, текст в карточке → ⚠ (воспроизвести CTL-052: текст «Укажите новое значение» стоит в соседних
  строках, в своей — пусто).

Несрабатывание:
- объединённая ячейка `colspan="2"` «логика + сообщение» и карточка с формулой объединённой ячейки → молчать;
- та же объединённая ячейка, а карточка несёт текст сообщения → **молчать** (это нарушение нормы, но другого класса:
  ячейка не пуста; ловит ревью, не этот сторож);
- хвост `rowspan` без собственных ячеек → не строка данных, молчать;
- типовая логика «Если значение реквизита указано, то …» у двух строк с разными реквизитами → разведение по
  заголовку карточки; при равных кандидатах с разной заполненностью → молчать;
- поле карточки «в постановке не задано» при пустой ячейке → молчать;
- файл без `confluence_page_ids` → одна `i`-строка на файл, ⚠ нет;
- колонка «Структура сообщения» (интеграция) → не колонка сообщения, молчать;
- строка-раздел шапки на всю ширину → не заголовок и не строка данных.

Объём по оценке замера: 250–300 строк и 10–12 тестов. Если выходит заметно больше — остановиться и спросить, не
резать условия.
