# Инструкция по установке и настройке ПО для системного аналитика

## Введение

Данный документ объединяет требования к настройке окружения для работы в рамках подхода **API First**, а также для использования утилит миграции и конвертации документации. Инструкция охватывает установку базовых инструментов (Git, VS Code), настройку окружения Python, браузера Chrome и драйвера Chromedriver, необходимых для работы с утилитами `confluence-tree-exporter` и `onix_offline`.

---

## Часть 1. Установка базового ПО

### 1.1 Установка Git

Git — система контроля версий, необходимая для работы с репозиторием спецификаций.

**Windows:**
1. Перейдите на официальный сайт: https://git-scm.com/downloads
2. Скачайте установщик для Windows
3. Запустите `.exe` файл
4. В мастере установки оставьте настройки по умолчанию (рекомендуется)
5. После установки проверьте: откройте `Командную строку` (cmd) и введите:
   ```bash
   git --version
   ```

**macOS:**
```bash
# Через Homebrew (рекомендуется)
brew install git

# Или скачайте установщик с официального сайта
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install git
```

### 1.2 Установка Visual Studio Code

VS Code — легковесный, но мощный редактор с отличной поддержкой YAML и OpenAPI.

1. Перейдите на официальный сайт: https://code.visualstudio.com/
2. Скачайте версию для вашей ОС
3. Запустите установщик и следуйте инструкциям

**Рекомендуемые плагины для VS Code:**

| Плагин | Назначение | Идентификатор |
|--------|------------|---------------|
| **OpenAPI (Swagger) Editor** | Подсветка синтаксиса, валидация, автодополнение для OpenAPI | `42Crunch.vscode-openapi` |
| **YAML** | Поддержка YAML-синтаксиса, валидация | `redhat.vscode-yaml` |

**Как установить плагины:**
1. Откройте VS Code
2. Нажмите `Ctrl+Shift+X` (Windows/Linux) или `Cmd+Shift+X` (macOS)
3. В поиске введите идентификатор плагина
4. Нажмите `Install`

## Часть 2. Настройка базового ПО

### 2.1 Настройка Git (выполняется один раз)

**Представьтесь системе Git** (обязательно, чтобы коммиты имели автора):
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваша.почта@example.com"
```

**Настройка автопреобразования концов строк** (важно для кросс-платформенной работы):
```bash
# Windows
git config --global core.autocrlf true

# macOS/Linux
git config --global core.autocrlf input
```

### 2.2 Настройка VS Code для работы с Git

VS Code имеет встроенную поддержку Git, дополнительной настройки не требуется. Основные элементы интерфейса:

| Элемент | Где находится | Назначение |
|---------|---------------|------------|
| **Source Control** | Левая панель (иконка с веткой) | Управление изменениями, коммиты, синхронизация |
| **Статусная строка** | Нижняя часть окна | Текущая ветка, количество изменений |

## Часть 3. Установка и настройка Python

Для работы утилит `confluence-tree-exporter` и `onix_offline` требуется окружение Python.

### 3.1 Установка Python

**Windows:**
1. Перейдите на официальный сайт: https://www.python.org/downloads/
2. Скачайте установщик для Python 3.12.x
3. Запустите установщик
4. **Обязательно** отметьте галочку `Add Python to PATH`
5. Выберите `Install Now`
6. После установки проверьте:
   ```bash
   python --version
   ```
   > Должно выводиться `Python 3.12.xxx`

**macOS:**
```bash
# Через Homebrew
brew install python@3.12

# Проверка
python3 --version
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update
sudo apt install python3.12 python3.12-venv python3-pip

# Проверка
python3.12 --version
```

### 3.2 Настройка PATH (важно при нескольких версиях Python)

Если установлено несколько версий Python, убедитесь, что по умолчанию запускается Python 3.12:

**Windows (проверка в cmd):**
```bash
where python
```
В результатах версия 3.12 должна быть первой.

**macOS/Linux:**
```bash
which python3
# или
which python3.12
```

При необходимости создайте алиас или измените порядок в PATH.

## Часть 4. Установка браузера Chrome и Chromedriver

Утилита `onix_offline` требует браузер Chrome и соответствующий драйвер Chromedriver.

### 4.1 Установка Google Chrome

**Для закрытого контура (VDI):**
- **Версия:** 149.0.7827.103 (официальная сборка, 32 бит)
- **Важно:** Версия Chrome обновляется автоматически администраторами. В случае повышения версии требуется переустановка в пути новой соответствующей версии Chromedriver.

**Для внешнего контура:**
- Поддерживаются Windows 32/64 бит, macOS
- Версия Chrome должна соответствовать версии Chromedriver по MAJOR.MINOR

**Скачать Chrome:**
- Официальный сайт: https://www.google.com/chrome/
- Для закрытого контура используйте корпоративный репозиторий или установщик, предоставленный администраторами.

### 4.2 Установка Chromedriver

**Для закрытого контура (VDI):**
- **Версия:** 149.0.xxxx.yyy (входит в состав бандла `onix_offline`)
- **Требования:**
  - MAJOR.MINOR версии Chromedriver и его разрядность ДОЛЖНЫ совпадать с MAJOR.MINOR версии Chrome
  - Совместимость "примерно" или между разными версиями не поддерживается

**Для внешнего контура:**
- Chromedriver для Windows 32 входит в состав бандла
- Рекомендуется использовать автоматическое обновление согласно инструкции из пакета
- **Важно:** MAJOR.MINOR версии Chromedriver и его разрядность ДОЛЖНЫ совпадать с MAJOR.MINOR версии Chrome

**Где скачать Chromedriver:**
- Официальный сайт: https://chromedriver.chromium.org/downloads
- Выбирайте версию, строго соответствующую вашей версии Chrome

**Проверка версии Chrome:**
```bash
# В адресной строке Chrome введите:
chrome://version/
```

**Установка:**
```
Описана в файле README архива с утилитой.
```

### 5.2 Утилита `onix_offline`

Предназначена для переноса файлов/каталогов между контурами.

**Предварительные требования:**

| Компонент | Закрытый контур (VDI)           | Внешний контур |
|-----------|---------------------------------|----------------|
| **Python** | 3.12.XXX в PATH                 | 3.12+ в PATH |
| **Chrome** | 149.0.сссс.mmm (32 бит)      | Версия XX.YY.MM.NN (официальная сборка) |
| **Chromedriver** | 149.0.xxxx.yyy (входит в бандл) | XX.YY.ZZ.LL (автообновление или ручная установка) |
| **ОЗУ** | 12+ ГБ (рекомендуется)          | 12+ ГБ (рекомендуется) |

> **Важное замечание:** Теоретически утилита может работать и на 8 ГБ ОЗУ, но скорость передачи будет ниже, и требуется подбор комбинации настроек.

**Установка:**
```
Описана в файле INSTALL.txt архива с утилитой.
```

**Проверка после установки:**
```bash
# Проверка версии Chromedriver
chromedriver --version

# Проверка доступности Chrome
google-chrome --version  # Linux
# или
chrome --version  # Windows/macOS
```

## Часто задаваемые вопросы (FAQ)

### Вопрос: Что делать, если при запуске утилиты возникает ошибка версии Chromedriver?
**Ответ:** Проверьте версию Chrome (`chrome://version/`) и убедитесь, что Chromedriver имеет ту же MAJOR.MINOR версию. Скачайте соответствующий драйвер с официального сайта.

### Вопрос: Как переключиться на Python 3.12, если установлено несколько версий?
**Ответ:** 
- Windows: измените порядок в переменной PATH или используйте полный путь, например `C:\Python312\python.exe`
- macOS/Linux: используйте `python3.12` или создайте алиас: `alias python=python3.12`

### Вопрос: Можно ли использовать другую версию Chrome?
**Ответ:** Только если Chromedriver строго соответствует этой версии по MAJOR.MINOR. Несовместимость приведёт к ошибкам при работе утилиты.

### Вопрос: Где взять бандлы утилит для закрытого контура?
**Ответ:** Обратитесь к лиду-аналитику.
