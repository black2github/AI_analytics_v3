## Найдено и исправлено по ходу

1. **Ложные ⚠ из-за плейсхолдеров в угловых скобках** (первый прогон — 3 ⚠: 2166860176 ×2,
   2166860206). В raw плейсхолдер атрибута стоит как есть (`<Признак открытия нового счета>`), в
   копии — `&lt;…&gt;`; нормализация снимала «всё в угловых скобках» как теги и выбрасывала его
   только со стороны raw, отчего законный текст вне удалений не засчитывался. Теперь снимаются только
   HTML-теги по закрытому перечню имён (блочные — пробелом, строчные — без пробела) одинаково для
   обеих сторон. Вид сериализации: критик/raw — литерал `<…>`, копия — сущности. Это дефект
   нормализации сторожа, не критика. Парный тест на срабатывание —
   `test_placeholder_in_angle_brackets_matches_escaped_copy`.
2. **Вставка невведённой задачи оправдывала недоснятие** (поймал тест
   `test_2_reinsert_by_not_introduced_task_does_not_excuse`). Расчёт «законно остаётся на странице»
   учитывал вставки невведённых задач, хотя применённая копия (reject-all) их снимает. Исправлено:
   из raw «как должно остаться» убираются удаления введённых и вставки невведённых задач.

Дефектов критика на КК не найдено (копия совпадает с тем, что даёт критик из raw).

## Правило, как реализовано

- **Введённая задача** — тег `src/<ID>` с HEAD (`kitcheck/checks/task_tags.task_tags` — один дом
  правила «введена = тег»; корень — ближайший каталог с `.git` над `--raw`); `--introduced <файл>` —
  ID по строке, строки `#` — комментарии. Нет ни того, ни другого — `i raw-оракул: введённых задач не
  найдено (теги src/*), проверка пропущена`.
- **Пара страниц** — по `confluence_page_id` обоих деревьев (`raw` при индексации копий пропускается),
  запасной способ — тот же относительный путь.
- **Нормализация** (`raw_oracle.normalize`, одна для обеих сторон): HTML-теги (закрытый перечень),
  маркеры CriticMarkup и значения `±ID` столбца status сняты; markdown-ссылка → её текст;
  экранирование `\[` раскрыто; `&lt;/&gt;/&amp;` раскрыты; `|` и блочные теги — пробел; пробелы
  схлопнуты; регистр не учитывается; пунктуация по краям снята. Порог — 4 слова и 20 символов
  (константы `MIN_WORDS`, `MIN_CHARS`).
- **Сравнение** — число вхождений фрагмента в копии против числа вхождений в raw «как должно
  остаться» (без удалений введённых и вставок невведённых задач): больше — ⚠ с `×N` для повторов;
  иначе — «законно встречается на странице вне удалений» (счётчик в i). Так текст, удалённый в одном
  месте и законно оставшийся в другом, не даёт сигнала, а недоснятие в том же месте — даёт.
- **Ограничители 1–7** — каждый тестом на НЕсрабатывание: задача без тега; текст вставлен введённой
  задачей; блок кода; ячейка вложенной таблицы острова (вложенность — предки `table` внутри острова,
  собственная таблица острова не вложенная; ключ `--include-nested-cells` включает); короткие;
  страница без копии; повторы — одна строка `×N`.
- **Строки отчёта** (замечание владельца 25.10 — слово «оракул» в отчётах не употребляется, только
  в имени модуля): `⚠ сверка по архиву raw: удалённое введённой задачей <ID> осталось в применённой
  копии страницы <page_id> (<файл>:<строка>) [×N] — «<фрагмент>»`; `i сверка по архиву raw: введённые
  задачи …; страниц с маркерами удаления …, удалённых фрагментов проверено …, находок …; законно
  встречаются на странице вне удалений …`; `i сверка по архиву raw: пропущено удалённых фрагментов в
  ячейках вложенных таблиц: N (…); короткие …; вставлены введённой задачей …; страниц без применённой
  копии …`; без бандла — `⚠ сверка по архиву raw не выполнена: бандл не найден (--bundle …)`.
  Заголовок отчёта по карточкам — «Сверка по архиву raw: удалённое введёнными задачами осталось в
  карточках комплекта».
- **Режим карточек** (второй срез, развилка владельца) — не делался; `check_page(raw, target, …)`
  принимает любой текст-цель, режим карточек ляжет без переписывания.

## Второй срез — режим карточек (решение владельца пилота 25.10)

`raw_oracle.py --cards <docs> --raw <sources/raw> [--introduced <файл>] [--skip-nested-cells] --out <md>` —
отдельный отчёт, не selfcheck. Цель — карточки `docs/`, в `confluence_page_ids` которых стоит
page_id страницы; сверка та же. Введённые задачи без `--introduced` — теги `src/*` по правилу
бандла (`apply_history.introduced_tasks`). Отчёт: сводка, по задачам, по карточкам, таблица «Карточка
| Раздел карточки | Страница | Задача | Фрагмент (120) | Строка | Проверить»; нулевой результат —
явной строкой; время прогона.

- **Исключения в карточке** — закрытый перечень разделов по шаблонам канона: «Происхождение»,
  «Долги и открытые вопросы», «Открытые вопросы», «Что не переносится из источника», «Изображения
  источника», «Источники миграции», «Долги по ссылкам» (до следующего заголовка того же или
  старшего уровня), плюс строки со ссылкой `OQ-NNN` или словом «долг». «Примечания к переносу» (КК,
  не канонический раздел) не исключаются — видны колонкой «Раздел карточки».
- **Калибровка (25.10):** порог 4 слова / 20 символов не поднимается (пропуск хуже шума); фрагмент
  из 4 слов или короче 30 символов помечается «проверить». Ячейки вложенных таблиц в режиме
  карточек проверяются по умолчанию (`--skip-nested-cells` — пропуск); в selfcheck умолчание прежнее.
- **Нормализация markdown против HTML** (найдено при калибровке): карточка несёт `**…**`, `` ` ``,
  «ёлочки», архив — `<strong>`, прямые кавычки; без сведения у SCR-CL-20 из 56 фрагментов не
  совпадало ни одно (фиктивный ноль). Сводится симметрично: `**`/`__`/`` ` `` сняты, кавычки
  «»“”„" → ", «ё» → «е». Парный тест `test_cards_markdown_card_matches_html_raw`. Режим копий после
  этого: КК 0 ⚠, отрицательный полигон 1.
- **КК при 0e32b01** (9,2 с): страниц с удалениями введённых задач 12, из них без карточки 5;
  карточек 14; проверено 249 фрагментов; **находок 21** — SCR-CL-19 14, SCR-CL-20 6, SCR-CL-22 1;
  по задачам TEAMTB-3633 — 14, TEAMTB-3846 — 7, TEAMTB-3716 и 3969 — 0; «проверить» 3; вставлены
  введённой задачей 32; во вложенных ячейках 0 (таких удалений в архиве КК нет). Первый прогон до
  калибровки — 13 (все в SCR-CL-19).
- **Модель подтверждается:** находки только там, где карточка старше ввода задачи (SCR-CL-19/20/22 ←
  3633/3846); у 3716 и 3969 — 0, их страницы переносились по срезу с уже применёнными задачами.
- **Тесты:** в `tests/test_raw_oracle.py` режиму карточек — 11 (положительный, чистая карточка и
  строка «находок нет», карточка другой страницы, исключённые разделы и граница раздела, строки
  долга/OQ, невведённая задача, CLI-отчёт, markdown против HTML, вложенные ячейки по умолчанию и
  ключ, «проверить»); всего в файле 34.
