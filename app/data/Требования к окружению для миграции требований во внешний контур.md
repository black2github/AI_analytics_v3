# Инструкция для системного аналитика: Настройка окружения для переноса аналитики во внешний контур

В данном документе описаны требования к настройке **окружения**, которые должны быть 
выполнены/удовлетворены до того, как вы приступите к использованию пакетов, указанных ниже. 
Порядок работы с самими пакетами - вне рамок данного документа.

## Утилита конвертации страниц Confluence в Markdown формат
Пакет предназначен для конвертации набора требований (дерева Confluence страниц) в markdown формат.

### VDI (закрытый контур)

**Наименование пакета/бандла**:  confluence-tree-exporter 

- **Предварительные требования**
    - python 3.12.XXX доступный в PATH. Если установлено несколько версий python, то по умолчанию должна запускаться версия 3.12.XXX.

### Внешний контур

**Наименование пакета/бандла:**  confluence-tree-exporter 

- **Предварительные требования**
    - python 3.12+, доступный в PATH.

## Утилита переноса файлов/каталогов между контурами
Пакет предназначен для переноса файлов требований.

### VDI (закрытый контур)

**Наименование пакета/бандла**:  onix_offline

- **Предварительные требования**:
    - python 3.12.XXX доступный в PATH. Если установлено несколько версий python, то по умолчанию должна запускаться версия 3.12.XXX.
    - Chrome:  - Версия: 149.0.7827.103 (официальная сборка) (32 бит)
    - Chromedriver: 149.0.xxxx.yyy (входит в состав бандла)
        > Важно: 1. MAJOR.MINOR версии Chromedriver и его разрядность ДОЛЖНЫ совпадать с MAJOR.MINOR версии Chrome, никаких “примерно” или совместимостей сверху вниз или снизу вверх не поддерживается. 2. **Версия Chrome обновляется автоматически администраторами**. В случае повышения версии требуется переустановка в пути новой соответствующей версии Chromedriver. 
        
    - 12+ Gb оперативной памяти на VDI.
        
        > Замечание: Теоретически должно запускаться и на 8 Gb, но пока вариантов настроек не подобрано. И в любом случае, при 8 Gb скорость передачи будет ниже, чем при 12+ Gb, а она и так не велика.

### Внешний контур

**Наименование пакета/бандла**:  onix_offline 

- **Предварительные требования**:
    - Windows 32/64, Mac
    - python 3.12.+ доступный в PATH.
    - Chrome:  - Версия: XX.YY.MM.NN (официальная сборка)
    - Chromedriver: XX.YY.ZZ.LL (для Windows 32 входит в состав бандла, но проще настройками по инструкции использовать автоматическое обновление)
        > Важно: 1. MAJOR.MINOR версии Chromedriver и его разрядность ДОЛЖНЫ совпадать с MAJOR.MINOR версии Chrome, никаких “примерно” или совместимостей сверху вниз или снизу вверх не поддерживается.
    - 12+ Gb оперативной памяти.
        > Замечание: Теоретически должно запускаться и на 8 Gb, но пока вариантов настроек не подобрано. И в любом случае, при 8 Gb скорость передачи будет ниже, чем при 12+ Gb, а она и так не велика.
