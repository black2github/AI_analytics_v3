## 1. Два промпта в шаге 2.1 — допустимо, решение принято

Шаг 2.1 написан как «один прогон», потому что на 25.10 единственным заходом по экранным формам был
ISS-03-R2. Заход DELTA-3633 по страницам задачи — тот же источник 0e32b01 (выгрузка 24.10 — ПРОМ-срез, в
котором TEAMTB-3633 уже введена), поэтому раскладка на два промпта плану не противоречит: цель шага —
соответствие карточек срезу 0e32b01, а не число прогонов. Условия, при которых двойной работы и потерь нет:

1. Источник обоих прогонов — применённая копия страниц в `sources/confluence/` на 0e32b01; ничего не берётся
   из старых выгрузок.
2. Каждая карточка — ровно в одном из прогонов. В сдаче 2.1 — список: какие карточки собрал ISS-03-R2, какие
   DELTA-3633 (заходы 1/3/6).
3. Все 21 фрагмент из отчёта сверки по архиву raw (25.10) распределены по промптам: SCR-CL-19 — закрыт
   приёмкой 6c426d0; SCR-CL-20 и SCR-CL-22 — заходы DELTA-3633. Фрагмент без промпта — потеря.
4. Выход из шага 2.1 — повторный отчёт `raw_oracle.py --cards` по карточкам обоих прогонов пуст. Этим шаг
   закрывается, а не окончанием последнего захода.
5. Ревью 2.2 и приёмка 2.3 — по объединению карточек обоих прогонов, одной приёмкой: акцептующей не нужно
   принимать ISS-03-R2 и DELTA-3633 порознь.

Поправка нумерации в вашем сообщении: заходы DELTA-3633 — часть шага 2.1 (пересборка), а 2.2 — отдельный
запуск ревьюера по готовому объединённому заходу. Строку 2.1 плана я переписал под два прогона; статус 2.1 ▶.

## 2. Окна приёмки акцептующего — организационный шаг за мной

Ручные шаги 2.3, 3.4, 4.5 и 5.3 — критический путь плана; время согласую с акцептующей напрямую. Чтобы
согласование было предметным, прошу от координатора по каждому из них за день до готовности: что
предъявляется (список карточек), отчёт ревьюера и ориентировочный объём чтения — акцептующая выбирает
между приёмкой по мере готовности и приёмкой пакетами. Для 2.3 ориентир: после отчёта ревьюера по
объединённому заходу; для 3.4 — пакетами по типам карточек в порядке списков 25.10 (контроли и модели
данных — целиком, остальное — по выборке из замечаний ревьюера).
