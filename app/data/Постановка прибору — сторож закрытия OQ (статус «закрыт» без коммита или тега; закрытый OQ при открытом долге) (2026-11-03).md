# Постановка прибору — сторож закрытия OQ (статус «закрыт» без коммита или тега; закрытый OQ при открытом долге) (2026-11-03)

Кому: сессия «Правки прибора, акцепт и рутина». От: «Точки расширения эталона». Срочность: обычная (после тега prom-slice-0e32b01-accepted; первая волна ответов аналитиков OQ-R1 ещё пуста). ## Норма (дом — гид миграции `_meta/migration/reference.md`, абзац «Вопросы агентов к источнику — записями OQ-NN…»; дописать абзацем рядом, старые журналы не переписываются)

Ответ на вопрос не закрывает запись и не правит карточку; закрывает коммит одного из трёх каналов. Форма строки статуса закрытой записи с даты нормы:

- `- Статус: закрыт: <ГГГГ-ММ-ДД>, <коммит 7–40 hex или тег src/<ID>>, затронуто: <ID карточек через запятую>` — канал «комплект» (коммит захода) или «источник» (тег ввода задачи; без Jira — тег `src/OQ-NNN`);
- `- Статус: закрыт: <ГГГГ-ММ-ДД>, без изменений: <кто ответил, где>` — ответ подтвердил текущее состояние карточек;
- промежуточные статусы: `- Статус: ответ получен, разбор` → `- Статус: ответ получен, канал: источник, задача <ID>` / `канал: комплект, tasks/<ID>` — записи с ними считаются открытыми (класс «открыт» для B9 и гейта).

Долг матрицы вида «открытый вопрос» с `источник: OQ-NNN` при закрытии записи получает приписку в конце строки (append-only): `; закрыт: <ГГГГ-ММ-ДД>, <коммит/тег>` (или `; закрыт: <дата>, без изменений`). Долг без цели со строкой `закрыт: <дата>` — закрытый долг; в счёт открытых не входит, печатается строкой `i` в сводке (как закрытые долги с появившейся целью).

Дата нормы — дата вливания в канон (константа в приборе `OQ_CLOSE_FORM_SINCE`); записи, закрытые до неё в прежних формах («закрыт 2026-09-17 — принято решение…», «закрыта», «решён», «реализовано», «снят»), норма не трогает.

## Задача 1 (B10). Статус «закрыт» без коммита, тега или «без изменений»

Дом: `kitcheck/checks/review_guards.py` рядом с B9 (общие `oq_entries`, `OQ_STATUS_RE`, `oq_status_class`); слой — ядро.

Сигнал: запись журнала, у которой класс статуса «закрыт» (`oq_status_class`) и в строке статуса есть дата (ISO или ДД.ММ.ГГГГ) ≥ `OQ_CLOSE_FORM_SINCE`, но нет ни хеша (7–40 hex; 9–10 цифр подряд — page_id, не коммит), ни тега (`src/…`, либо имя тега вида `<слово>-<hex>-accepted`), ни слов «без изменений» → ⚠ «OQ-NNN закрыт без коммита, тега или «без изменений» (норма закрытия с <дата>)». Запись без даты в строке статуса или с датой < нормы — пропуск (legacy). «затронуто:» — поле рекомендованное, не обязательное.

НЕсрабатывание: «закрыт 2026-09-17 — принято решение: вариант 1» (дата < нормы) — ✓; «закрыт: 2026-11-05, без изменений: аналитик КК, приёмка 03.11» — ✓; «закрыт: 2026-11-05, a1b2c3d4, затронуто: CALL-EXT-011» — ✓; «закрыт: 2026-11-05, src/OQ-378» — ✓; «закрыт: 2026-11-05» — ⚠; «ответ получен, разбор» — класс «открыт», не ⚠ этой проверки.

## Задача 2 (link_debts). Закрытый OQ при открытом долге того же источника

Дом: `link_debts.py` (ядро, всегда), раздел долгов без цели (он уже требует `источник: OQ-NNN` у вида «открытый вопрос»). Журнал `open-questions.md` — по локатору файлов комплекта `kitcheck/fs.find_kit_file` (корень комплекта, затем родитель); журнала нет (целевой docs-репозиторий) — проверка молча не применяется, строка `i` (только если есть долги по OQ).

Сигнал: долг без цели вида «открытый вопрос» со `источник: OQ-NNN`, у которого в строке нет `закрыт: <дата>`, а запись OQ-NNN закрыта по новой форме (дата ≥ нормы) → ⚠ «долг <FROM-ID> по OQ-NNN открыт, а запись закрыта <дата> (<коммит/тег>) — допишите закрытие долга или снимите статус». Обратное направление (долг закрыт, запись открыта) — тоже ⚠. Запись закрыта в прежней форме — пропуск.

Сводка link_debts: закрытые долги без цели (строка `закрыт: <дата>`) не входят в счёт открытых, печатаются строкой `i закрытых долгов без цели: N`. На КК master d60824bc ожидание — без изменений (232, 0 ⚠ новых).

НЕсрабатывание: долг с `закрыт: 2026-11-05, a1b2c3d4` + запись закрыта той же формой — ✓; долг открыт + запись «зафиксировано» — ✓; долг открыт + запись «закрыт 2026-09-17 — …» (legacy) — ✓ без ⚠.
