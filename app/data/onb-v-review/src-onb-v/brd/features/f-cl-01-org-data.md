# Фича: Ввод данных организации/ИП (F-CL-01)

*Реконструкция по комплекту SRS (reverse-from-SRS); не является требованиями заказчика. Трассировка на этот документ ловит рассинхроны последующих изменений; исходные ошибки SRS она не выявляет — документ выведен из него же.*

Связная способность: пользователь внешней части сайта сообщает данные своей организации или ИП для будущей заявки. Сквозной сценарий — [UC-01](../use-cases/uc-01-open-account.md).

## US-01 — Ввод данных организации/ИП

Как пользователь внешней части сайта, я хочу заполнить данные своей организации или ИП с подсказками или вручную, чтобы начать оформление заявки на открытие первого счёта онлайн.

### Функциональные требования (EARS)

- FR-01.1 (event): Когда пользователь нажимает кнопку «Открыть счёт» на лендинге или переходит по ссылке-приглашению из электронной почты, система должна открывать форму ввода данных организации/ИП.
- FR-01.2 (event): Когда пользователь переходит по несуществующему адресу любой страницы сервиса (страница не найдена), система должна направлять его на форму ввода данных организации/ИП.
- FR-01.3 (optional): Где сервис открыт для внешних пользователей, система должна предоставлять формы оформления.
- FR-01.4 (event): Когда пользователь вводит в поле выбора организации не менее двух символов, система должна отображать подсказки с найденными организациями и ИП (краткое наименование, ИНН, адрес).
- FR-01.5 (event): Когда пользователь выбирает ввод данных вручную, система должна открывать форму ручного ввода реквизитов (краткое наименование, ИНН, КПП, город обслуживания, тип счёта).
- FR-01.6 (optional): Где подсказки по организациям отключены настройкой сервиса, система должна сразу открывать форму ручного ввода реквизитов.
- FR-01.7 (optional): Где данные организации вводятся с подсказками, система должна предлагать города обслуживания согласно [BR-05](../business-rules.md).
- FR-01.8 (unwanted): **Если** введённые данные организации не проходят проверки, **то** система должна отображать сообщения у соответствующих полей и не переходить к следующему шагу оформления.
- FR-01.9 (unwanted): **Если** доступность сервиса выключена, **то** система должна направлять пользователя на аутентификацию в ГПБ Бизнес-Онлайн ([BR-07](../business-rules.md)).
- FR-01.10 (optional): Где данные организации вводятся вручную, система должна предлагать города обслуживания из справочника городов.
- FR-01.11 (unwanted): **Если** ИНН организации начинается на 9909, **то** система должна сообщать, что сервис недоступен иностранным юридическим лицам, и не переходить к следующему шагу оформления.

### Критерии приёмки (Gherkin)

```gherkin
@FR-01.1
Сценарий: Переход на оформление с лендинга
  Дано пользователь находится на лендинге внешней части сайта
  Когда пользователь нажимает кнопку "Открыть счёт"
  Тогда открывается форма ввода данных организации/ИП

@FR-01.2
Сценарий: Переход по несуществующему адресу
  Дано сервис открыт для внешних пользователей
  Когда пользователь переходит по адресу, для которого страница не найдена
  Тогда пользователь попадает на форму ввода данных организации/ИП

@FR-01.3
Сценарий: Сервис открыт
  Дано доступность сервиса для внешних пользователей включена настройкой
  Когда пользователь переходит на форму оформления
  Тогда форма открывается и доступна пользователю

@FR-01.4
Сценарий: Подсказки по организации
  Дано пользователь на форме ввода данных организации
  Когда пользователь вводит в поле выбора организации не менее двух символов
  Тогда отображается список найденных организаций и ИП с наименованием, ИНН и адресом

@FR-01.4
Сценарий: Мало символов для поиска
  Дано пользователь на форме ввода данных организации
  Когда пользователь вводит в поле выбора организации менее двух символов
  Тогда подсказки не отображаются

@FR-01.5
Сценарий: Ручной ввод реквизитов
  Дано пользователь на форме ввода данных организации
  Когда пользователь выбирает "Ввести данные организации вручную"
  Тогда открывается форма ручного ввода: краткое наименование, ИНН, КПП, город обслуживания, тип счёта

@FR-01.6
Сценарий: Подсказки отключены настройкой
  Дано подсказки по организациям отключены настройкой сервиса
  Когда пользователь начинает оформление
  Тогда сразу открывается форма ручного ввода реквизитов

@FR-01.7
Сценарий: Города обслуживания при вводе с подсказками
  Дано пользователь вводит данные организации с подсказками
  Когда пользователь открывает список городов обслуживания
  Тогда отображаются города действующих подразделений банка, оказывающих перечисленные в BR-05 услуги, без дубликатов, по алфавиту

@FR-01.8
Сценарий: Данные не проходят проверку
  Дано пользователь заполнил данные организации с ошибкой
  Когда пользователь подтверждает данные
  Тогда у соответствующих полей отображаются сообщения об ошибках
  И переход к следующему шагу не выполняется

@FR-01.9
Сценарий: Сервис выключен
  Дано доступность сервиса для внешних пользователей выключена настройкой
  Когда пользователь переходит на любую форму оформления
  Тогда пользователь направляется на аутентификацию в ГПБ Бизнес-Онлайн

@FR-01.10
Сценарий: Города обслуживания при ручном вводе
  Дано пользователь вводит данные организации вручную
  Когда пользователь открывает список городов обслуживания
  Тогда отображаются населённые пункты из справочника городов

@FR-01.11
Сценарий: ИНН иностранного юридического лица
  Дано пользователь ввёл ИНН, который начинается на 9909
  Когда пользователь подтверждает данные организации
  Тогда пользователю сообщается, что сервис недоступен иностранным юридическим лицам
  И переход к следующему шагу не выполняется
```
