# Фича: Удалённое открытие счёта по ссылке-приглашению (F-CL-04)

*Реконструкция по комплекту SRS (reverse-from-SRS); не является требованиями заказчика. Трассировка на этот документ ловит рассинхроны последующих изменений; исходные ошибки SRS она не выявляет — документ выведен из него же.*

Связная способность: пользователь, начавший оформление по ссылке-приглашению удалённого открытия счёта, направляется на страницу регистрации по короткой ссылке. Сквозной сценарий — [UC-01](../use-cases/uc-01-open-account.md).

## US-04 — Продолжение оформления удалённого открытия счёта

Как пользователь, пришедший по ссылке удалённого открытия счёта, я хочу перейти на страницу регистрации по короткой ссылке, чтобы продолжить удалённое открытие счёта без повторного ввода данных.

### Функциональные требования (EARS)

- FR-04.1 (event): Когда оформление начато с идентификатором удалённого открытия счёта и пользователь дал согласие ([BR-03](../business-rules.md)), система должна проверять возможность удалённого открытия счёта по этому идентификатору.
- FR-04.2 (event): Когда удалённое открытие счёта возможно, система должна формировать короткую ссылку и направлять пользователя по ней на страницу регистрации.
- FR-04.3 (unwanted): **Если** удалённое открытие счёта невозможно, **то** система должна продолжать оформление на сайте — на форме данных заявителя.
- FR-04.4 (unwanted): **Если** короткая ссылка не сформирована, **то** система должна продолжать оформление на сайте — на форме данных заявителя.

### Критерии приёмки (Gherkin)

```gherkin
@FR-04.1
Сценарий: Оформление с идентификатором удалённого открытия
  Дано оформление начато по ссылке с идентификатором удалённого открытия счёта
  И пользователь дал согласие
  Когда пользователь подтверждает данные организации
  Тогда система проверяет возможность удалённого открытия счёта по этому идентификатору

@FR-04.2
Сценарий: Переход на страницу регистрации по короткой ссылке
  Дано удалённое открытие счёта возможно
  Когда короткая ссылка сформирована
  Тогда пользователь перенаправляется по короткой ссылке на страницу регистрации

@FR-04.3
Сценарий: Удалённое открытие невозможно
  Дано оформление начато по ссылке с идентификатором удалённого открытия счёта
  Когда проверка показала, что удалённое открытие счёта невозможно
  Тогда оформление продолжается на сайте — открывается форма данных заявителя

@FR-04.4
Сценарий: Короткая ссылка не сформирована
  Дано удалённое открытие счёта возможно
  Когда короткая ссылка не сформирована
  Тогда оформление продолжается на сайте — открывается форма данных заявителя
```
