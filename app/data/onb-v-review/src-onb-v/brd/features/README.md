# Спецификации фич

Фича — связная область-способность актора. Поведение задано в EARS один раз, критерии приёмки — в Gherkin; правила — ссылками на [бизнес-правила](../business-rules.md), сквозные сценарии — на [use-cases](../use-cases/README.md). Связь фич с реализацией (функции, экраны, контроли) ведётся в [матрице трассировки](../../traceability-matrix.md) (разделы BRD-1…BRD-5).

**Эпик:** открытие первого счёта и регистрация клиента во внешней части сайта. Фичи сгруппированы по актору.
