# Фича: Выбор типа счёта (F-CL-02)

*Реконструкция по комплекту SRS (reverse-from-SRS); не является требованиями заказчика. Трассировка на этот документ ловит рассинхроны последующих изменений; исходные ошибки SRS она не выявляет — документ выведен из него же.*

Связная способность: пользователь выбирает тип открываемого счёта из предлагаемого перечня. Сквозной сценарий — [UC-01](../use-cases/uc-01-open-account.md).

## US-02 — Выбор типа счёта

Как пользователь внешней части сайта, я хочу выбрать подходящий тип открываемого счёта из предлагаемых, чтобы заявка соответствовала характеру моей деятельности.

### Функциональные требования (EARS)

- FR-02.1 (ubiquitous): Система должна предлагать типы счёта согласно настройке скрытия счетов ГОЗ ([BR-02](../business-rules.md), [ТР-01](../business-rules.md)).
- FR-02.2 (unwanted): **Если** индивидуальный предприниматель подтверждает данные организации с типом счёта «Счёт головного исполнителя ГК», **то** система должна отображать ошибку у поля типа счёта и не переходить к следующему шагу оформления ([BR-01](../business-rules.md)).
- FR-02.3 (optional): Где заключение двустороннего ДБС задано при переходе, система должна запрещать изменение типа счёта и, если тип счёта не получен из заявки CRM Infor или из сведений о лиде АС ППБ_СИП, предзаполнять его значением «Расчётный счёт».

### Критерии приёмки (Gherkin)

```gherkin
@FR-02.1
Сценарий: Скрытие счетов ГОЗ выключено
  Дано скрытие счетов ГОЗ выключено настройкой
  Когда пользователь открывает список типов счёта
  Тогда доступны "Расчётный счёт", "Счёт исполнителя ГК", "Счёт головного исполнителя ГК", "Счёт участника закупок"

@FR-02.1
Сценарий: Скрытие счетов ГОЗ включено
  Дано скрытие счетов ГОЗ включено настройкой
  Когда пользователь открывает список типов счёта
  Тогда доступны только "Расчётный счёт" и "Счёт участника закупок"

@FR-02.2
Сценарий: Тип, недоступный для ИП
  Дано организация является индивидуальным предпринимателем (ИНН 12 цифр)
  И выбран тип счёта "Счёт головного исполнителя ГК"
  Когда пользователь подтверждает данные организации
  Тогда у поля типа счёта отображается ошибка
  И переход к следующему шагу не выполняется

@FR-02.3
Сценарий: Тип задан при переходе
  Дано при переходе на оформление задано заключение двустороннего ДБС
  И тип счёта не получен из заявки CRM Infor или из сведений о лиде
  Когда пользователь открывает форму
  Тогда тип счёта предзаполнен значением "Расчётный счёт" и недоступен для изменения

@FR-02.3
Сценарий: Тип получен из заявки при заданном ДБС
  Дано при переходе на оформление задано заключение двустороннего ДБС
  И тип счёта получен из заявки CRM Infor или из сведений о лиде
  Когда пользователь открывает форму
  Тогда тип счёта предзаполнен полученным значением и недоступен для изменения
```
