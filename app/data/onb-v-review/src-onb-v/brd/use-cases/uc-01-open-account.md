# UC-01. Открытие первого счёта с внешнего сайта

*Реконструкция по комплекту SRS (reverse-from-SRS); не является требованиями заказчика. Трассировка на этот документ ловит рассинхроны последующих изменений; исходные ошибки SRS она не выявляет — документ выведен из него же.*

- **Область охвата:** сервис открытия 1-го счёта и регистрации клиента во внешней части сайта.
- **Актор:** Пользователь — посетитель внешней части сайта (будущий клиент) (основной). Вспомогательные: Система; сервис подсказки по организациям и ИП; сервис ОНБ_2021 (проверка возможности удалённого открытия счёта, создание заявки); сервис коротких ссылок; сервис регистрации пользователей; сервис Профиль (авторизация); сервис открытия счетов клиентам МСБ.
- **Заинтересованные стороны:** Банк — привлечение новых клиентов и открытие первого счёта; Пользователь — оформление заявки на открытие первого счёта онлайн; сервис открытия счетов клиентам МСБ — получение клиентов, профиль которых соответствует требованиям Короткой заявки.
- **Уровень:** цель пользователя.
- **Триггер:** пользователь нажал кнопку «Открыть счёт» на лендинге или перешёл по ссылке-приглашению из электронной почты.
- **Цель:** создать заявку на открытие первого счёта (или продолжить оформление в подходящем сервисе) с зарегистрированным и подтверждённым пользователем.
- **Зонд краевых случаев:** некорректные данные — покрыто (3b, 3c, 4a, 5a, 6a); недоступность смежной системы — покрыто (2b, 3e); прерывание/отмена — покрыто (*b); нет прав/полномочий — не обнаружено; конкурентный доступ — не обнаружено; граничные значения — покрыто (2a).

## Предусловия

1. Пользователь нажал кнопку «Открыть счёт» на лендинге или перешёл по ссылке-приглашению из электронной почты.

## Основной успешный сценарий

1. <u>Пользователь</u> переходит к оформлению с лендинга или по ссылке-приглашению.
2. <u>Пользователь</u> заполняет данные организации/ИП — по подсказкам или вручную — и выбирает тип счёта из предлагаемых ([BR-02](../business-rules.md), [BR-05](../business-rules.md); [F-CL-01](../features/f-cl-01-org-data.md), [F-CL-02](../features/f-cl-02-account-type.md)).
3. <u>Пользователь</u> подтверждает данные организации.
4. <u>Пользователь</u> заполняет данные заявителя (ФИО, мобильный телефон, email), вводит код с картинки, даёт согласие на обработку персональных данных и принимает условия резервирования счёта ([BR-03](../business-rules.md); [F-CL-03](../features/f-cl-03-applicant-registration.md)).
5. <u>Система</u> регистрирует заявителя и отправляет код подтверждения по СМС.
6. <u>Пользователь</u> вводит код подтверждения из СМС.
7. <u>Система</u> завершает регистрацию пользователя.
8. <u>Пользователь</u> авторизуется в ГПБ Бизнес-Онлайн.
9. <u>Система</u> направляет оформление согласно профилю пользователя ([ТР-02](../business-rules.md); [F-CL-05](../features/f-cl-05-continue-after-auth.md)): в сервис открытия счетов клиентам МСБ либо к созданию заявки на открытие первого счёта в сервисе ОНБ_2021, **завершение**.

## Альтернативы и исключения

- **1a. Доступность сервиса для внешних пользователей выключена ([BR-07](../business-rules.md)):** пользователь направляется на аутентификацию в ГПБ Бизнес-Онлайн, **завершение**.
- **1b. Переход по несуществующему адресу (страница не найдена):** пользователь направляется на форму ввода данных организации/ИП, **возврат к шагу 2**.
- **2a. Введено менее двух символов или организация не найдена в подсказках:** пользователь вводит реквизиты вручную (см. FR-01.5, FR-01.6 фичи [F-CL-01](../features/f-cl-01-org-data.md)), **возврат к шагу 2**.
- **2b. Сервис подсказки по организациям и ИП не ответил:** подсказки не отображаются, пользователь вводит реквизиты вручную, **возврат к шагу 2**.
- **3a. Оформление начато по ссылке удалённого открытия счёта и удалённое открытие возможно:** система формирует короткую ссылку и направляет по ней пользователя на страницу регистрации ([F-CL-04](../features/f-cl-04-remote-opening.md)), **завершение**.
- **3b. ИНН организации начинается на 9909:** пользователю сообщается, что сервис недоступен иностранным юридическим лицам, **возврат к шагу 2**.
- **3c. Данные организации не прошли проверки:** у полей отображаются сообщения об ошибках, пользователь исправляет данные, **возврат к шагу 2**.
- **3d. Удалённое открытие счёта невозможно:** оформление продолжается на сайте, **возврат к шагу 4**.
- **3e. Короткая ссылка не сформирована:** оформление продолжается на сайте, **возврат к шагу 4**.
- **4a. Данные заявителя не прошли проверки:** у полей отображаются сообщения об ошибках, пользователь исправляет данные, **возврат к шагу 4**.
- **5a. Код с картинки введён неверно:** отображается сообщение об ошибке у поля ввода кода, **возврат к шагу 4**.
- **6a. Введён неверный код подтверждения:** отображается сообщение об ошибке, **возврат к шагу 6**.
- **6b. Время ожидания кода истекло:** пользователь запрашивает код повторно, новый код отправлен на тот же номер, **возврат к шагу 6**.
- **\*a. Пользователь выбирает «Войти в ГПБ Бизнес-Онлайн» на шагах 2, 3, 4 или 6:** система сохраняет данные организации и передаёт их в процесс авторизации, **переход к шагу 8**.
- **\*b. Пользователь покинул страницу:** процесс завершается без создания заявки, **завершение**.
- **8a. Авторизация не пройдена:** процесс завершается, **завершение**.

## Постусловия

- **Успех:** заявка на открытие первого счёта создаётся в сервисе ОНБ_2021; либо пользователь передан в сервис открытия счетов клиентам МСБ; либо при удалённом открытии пользователь направлен на страницу регистрации по короткой ссылке.
- **Неуспех/отмена:** заявка не создана; процесс завершён.
