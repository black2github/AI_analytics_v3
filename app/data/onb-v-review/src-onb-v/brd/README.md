# Бизнес-требования (BRD)

Бизнес-требования к сервису: бизнес-правила, спецификации фич и сквозные сценарии. Детальное описание поведения системы — в разделах комплекта `srs/`; навигация — в [README комплекта](../README.md). **Точки входа:** [концепция сервиса](../service-vision.md) · [глоссарий](../glossary.md). BRD и SRS — разные слои (бизнес-аналитик / системный аналитик) и **не ссылаются друг на друга** в телах документов: связь бизнес-требований с реализацией ведётся в общей [матрице трассировки](../traceability-matrix.md) (разделы BRD-1…BRD-5).
