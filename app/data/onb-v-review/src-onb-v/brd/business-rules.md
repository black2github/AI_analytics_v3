# Бизнес-правила

*Реконструкция по комплекту SRS (reverse-from-SRS); не является требованиями заказчика. Трассировка на этот документ ловит рассинхроны последующих изменений; исходные ошибки SRS она не выявляет — документ выведен из него же.*

Только бизнес-правила — декларативно, машиночитаемо (RuleSpeak, DMN). Не-правила вынесены к владельцам в SRS (формат, длина и обязательность полей, тексты сообщений) — связь ведётся в [матрице трассировки](../traceability-matrix.md), ссылок на SRS здесь нет.

## 1. Атомарные правила (RuleSpeak)

| ID | Правило | Контур |
|---|---|---|
| BR-01 | Индивидуальный предприниматель (организация с ИНН длиной 12 цифр) **не должен** оформлять заявку на тип счёта «Счёт головного исполнителя ГК». | подача |
| BR-02 | Перечень типов счёта, предлагаемых для выбора, **определяется как** результат ТР-01 по настройке скрытия счетов ГОЗ. | подача |
| BR-03 | Пользователь **должен** дать согласие на обработку персональных данных и принять условия резервирования счёта до продолжения оформления заявки. | подача |
| BR-05 | При вводе данных организации с подсказками перечень городов обслуживания **определяется как** города действующих подразделений банка, оказывающих хотя бы одну из услуг: банковское сопровождение ЮЛ, ИП [СОПРЮЛ]; банковское сопровождение ЮЛ, ИП по ГОЗ [СОПРЮЛГОЗ]; привлечение клиентов / открытие счетов ЮЛ, ИП [ПРИВОТКРЮЛ]; привлечение клиентов / открытие счетов ЮЛ, ИП по ГОЗ [ПРИВОТКРЮЛГОЗ]; РКО ЮЛ, ИП [РКОЮЛ]. | подача |
| BR-06 | Пользователь, профиль которого соответствует требованиям Короткой заявки, **должен** направляться в сервис открытия счетов клиентам МСБ для продолжения оформления (см. ТР-02). | обработка |
| BR-07 | При выключенной доступности сервиса пользователь **должен** направляться на аутентификацию в ГПБ Бизнес-Онлайн. | подача |

## 2. Таблицы решений (DMN)

**ТР-01 — Типы счёта, предлагаемые для выбора** · Hit policy: U

| Скрытие счетов ГОЗ (настройка) | Предлагаемые типы счёта |
|---|---|
| включено | Расчётный счёт; Счёт участника закупок |
| выключено | Расчётный счёт; Счёт исполнителя ГК; Счёт головного исполнителя ГК; Счёт участника закупок |

**ТР-02 — Маршрутизация после авторизации** · Hit policy: U

| Проверка профиля выполнялась | Результат проверки | Продолжение оформления |
|---|---|---|
| нет | — | переход к созданию заявки на открытие первого счёта в сервисе ОНБ_2021 |
| да | профиль соответствует требованиям Короткой заявки | перенаправление в сервис открытия счетов клиентам МСБ |
| да | иной результат (не соответствует, ошибка, таймаут) | переход к созданию заявки на открытие первого счёта в сервисе ОНБ_2021 |
