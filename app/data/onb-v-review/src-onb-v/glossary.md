# Глоссарий домена

Единая терминология сервиса «[ОНБ_В] Сервис открытия 1-го счета и регистрации клиента во внешней части сайта»: единый источник согласованных определений предметной области для всех документов комплекта и его участников.

## 1. Сервис и продукт

| Термин | Определение | Синонимы |
|---|---|---|
| **onboarding-external** | Сервис, обеспечивающий открытие первого счёта и регистрацию клиента во внешней части сайта: приём данных организации/ИП и заявителя, регистрация с подтверждением телефона, переход к созданию заявки. | ОНБ_В |
| **Внешняя часть сайта** | Публичная часть сайта банка, доступная посетителю без авторизации, где размещены формы оформления первого счёта. | — |
| **Лендинг** | Целевая страница внешней части сайта с кнопкой «Открыть счёт», ведущей на оформление. | — |
| **Заявка на открытие первого счёта** | Заявка, формируемая по итогам оформления и передаваемая в сервис создания заявки; включает данные организации/ИП и заявителя. | Заявка на открытие первого счета_2021 |
| **Удалённое открытие счёта** | Сценарий, при котором пользователь начинает оформление по ссылке-приглашению с идентификатором и продолжает его по короткой ссылке на странице регистрации. | — |
| **Короткая ссылка** | Сокращённый адрес, сгенерированный сервисом коротких ссылок для перенаправления пользователя на страницу регистрации. | — |

## 2. Роли и акторы

| Термин | Определение | Синонимы |
|---|---|---|
| **Пользователь** | Посетитель внешней части сайта, оформляющий первый счёт для организации или ИП; до завершения регистрации авторизации не требует. | Посетитель |
| **Заявитель** | Физическое лицо, которое регистрируется пользователем Клиента: заполняет персональные данные и подтверждает номер телефона. | — |
| **Клиент** | Организация или ИП, открывающая счёт; данные организации заполняются на первом шаге оформления. | — |

## 3. Реквизиты и типы объектов

| Термин | Определение | Синонимы |
|---|---|---|
| **ИНН** | Идентификатор организации или ИП; длина 10 цифр соответствует юридическому лицу, 12 — индивидуальному предпринимателю. | — |
| **КПП** | Реквизит юридического лица; заполняется, когда ИНН состоит из 10 цифр. | — |
| **ОГРН** | Реквизит организации из ответа сервиса подсказки по организациям и ИП; используется для проверки профиля клиента. | — |
| **Расчётный счёт** | Тип открываемого счёта, доступный всем организациям; подставляется автоматически, если задано заключение двустороннего ДБС. | — |
| **Счёт исполнителя ГК** | Тип открываемого счёта; предлагается, когда скрытие счетов ГОЗ выключено. | — |
| **Счёт головного исполнителя ГК** | Тип открываемого счёта; предлагается, когда скрытие счетов ГОЗ выключено; недоступен индивидуальным предпринимателям. | — |
| **Счёт участника закупок** | Тип открываемого счёта; предлагается при любой настройке скрытия счетов ГОЗ. | — |
| **Заключение двустороннего ДБС** | Признак, передаваемый при переходе на оформление; при заданном признаке тип счёта недоступен для изменения. | bilateralContract |
| **Скрытие счетов ГОЗ** | Настраиваемый параметр сервиса для скрытия возможности выбора счёта ГОЗ при формировании заявки на открытие первого счёта. | disableGOZ |
| **Согласие на обработку персональных данных** | Обязательное согласие пользователя, объединённое с принятием условий резервирования счёта; без него продолжение оформления невозможно. | — |
| **Резервирование номера счёта** | Услуга банка по онлайн-резервированию номера банковского счёта на условиях, принимаемых пользователем при оформлении. | — |

## 4. Смежные системы и сервисы

| Термин | Определение | Синонимы |
|---|---|---|
| **Сервис подсказки по организациям и ИП** | Платформенный сервис автодополнения реквизитов по мере ввода; возвращает наименование, ИНН, КПП, адрес, город и ФИО для ИП. Описан как [PLT-004 Сервис подсказки по организациям и ИП](srs/platform-functions.md#plt-004-сервис-подсказки-по-организациям-и-ип). | DaData |
| **ОНБ_2021** | Смежный сервис открытия 1-го счёта клиента (онбординг): выполняет поиск заявки по идентификатору CRM, проверку возможности удалённого открытия и создание заявки. | Сервис открытия 1-го счета клиента (онбординг) |
| **ОНБ_КЗ** | Смежный сервис открытия счетов клиентам МСБ; определяет профиль клиента и обслуживает Короткую заявку. | Сервис открытия 1го счёта клиентам МСБ |
| **ОНБ_МСБ** | Сквозной бизнес-процесс сервиса ОНБ_КЗ, в который перенаправляется пользователь с соответствующим профилем. | — |
| **СКС** | Сервис генерации коротких ссылок для перенаправления на страницу регистрации. | — |
| **UAA** | Сервис регистрации пользователей: первоначальная регистрация, подтверждение и завершение регистрации по СМС-коду. | — |
| **Профиль** | Смежный сервис, отвечающий за процессы регистрации и авторизации пользователя Клиента. | — |
| **ГПБ Бизнес-Онлайн** | Система электронного документооборота — Экосистема, сервисом которой является и этот сервис; пользователь направляется в неё для авторизации и продолжения оформления. | Бизнес-Онлайн |
| **АС ППБ_СИП** | Внешняя автоматизированная система, источник сведений о лиде для открытия первого счёта (заполняется при переходе с сайта банка). | — |
| **CRM Infor** | Внешняя CRM-система; хранит идентификатор заявки на продажу, передаваемый при оформлении. | — |
| **Короткая заявка** | Заявка сервиса ОНБ_КЗ; пользователь, профиль которого соответствует её требованиям, направляется в этот сервис. Соответствие определяется по ОГРН организации. | — |
