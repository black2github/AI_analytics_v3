# ЭФ Клиента «Ввод данных заявителя с внешнего сайта»

## 1. Назначение

ЭФ предназначена для регистрации нового пользователя клиента банка

**Как перейти:**

Перейти на ЭФ пользователь Клиента может:

- по кнопке "Открыть счёт" с [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md)
- по кнопке "Назад" с [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](scr-cl-04-phone-confirm.md)
- По кнопке браузера "Вперед" с [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](scr-cl-02-org-data-no-dadata.md), [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md)
- По кнопке браузера "Назад" с [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](scr-cl-04-phone-confirm.md)

## 3. Видимость блоков

- «Блок регистрации пользователя клиента» — отображается всегда; название блока на ЭФ не отображается.
- «Блок прохождения капчи» — отображается всегда; название блока на ЭФ не отображается.

## 4. Правила полей

### FLD-1. «Баннер MW»

- **Тип:** Гиперссылка
- **Способ заполнения:** Автоматически
- **Обязательность:** Да
- **Видимость:**
  - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» (не равно) != true **или** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«S» (не равно) != true,
  - **то** отображается в верхней части ЭФ,
  - **иначе** отображается по тапу на иконку в нижней части ЭФ
  - Данный баннер должен отображаться на всех страницах авторизации.
- **Логика установки значения:** = "Лучший цифровой банк для корпоративных клиентов<br>ТОП-1 в рейтинге Markswebb"
- **Действие:** Кликабельный баннер с информацией о рейтинге MarksWebb. По нажатию на баннер открывается модальное окно: [PLT-003 Модальное окно "Первое место в рейтинге MW"](../../platform-functions.md#plt-003-модальное-окно-первое-место-в-рейтинге-mw)

      - [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр).«Тип данных содержимого» == SITE_MSB_GBPLEAD_ONBOARDING

    - «Содержимое» записи — сообщение АС ППБ_СИП_Получение лида для открытия первого счёта; поля ниже берутся по путям этого сообщения
    - **Если** запись сущности найдена,
    - **то** осуществляется автоматическое заполнение полей ЭФ:
      - FLD-4 «Фамилия» = [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр).«Содержимое».«Contact/LastName»
      - FLD-5 «Имя» = [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр).«Содержимое».«Contact/FirstName»
      - FLD-6 «Отчество» = [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр).«Содержимое».«Contact/MiddleName»

### EV-2. Ввод в поля FLD-4 «Фамилия», FLD-5 «Имя», FLD-6 «Отчество»

- **Если** "-" (дефис) или " " (пробел) или "'" (апостроф) или "." (точка) введены первым символом в поле,
- **то** символ автоматически удаляется
- **Если** два и более одинаковых символа "-" (дефис) или " " (пробел) или "'" (апостроф) или "." (точка) введены подряд,
- **то** все символы, кроме первого, автоматически удаляются


## 6. Кнопки

### B-1. «Обновить капчу» (под полем FLD-9 «Капча (ввод)»)

- **Видимость:** Описание см. для кнопки "Обновить" блока Регистрации на [Профиль] ЭФ Клиента "Регистрация"
- **При нажатии:** Описание см. для кнопки "Обновить" блока Регистрации на [Профиль] ЭФ Клиента "Регистрация"

### B-2. «Продолжить» (в конце формы, по центру)

- **Видимость:** Всегда
- **При нажатии:**
  - **Шаг 0.**
    - **Если** в полях FLD-4 «Фамилия», FLD-5 «Имя», FLD-6 «Отчество» последний символ " " (пробел),
    - **то** необходимо удалить этот пробел (последний символ в поле не должен быть пробелом)
    - **Если** в полях FLD-4 «Фамилия», FLD-5 «Имя», FLD-6 «Отчество» есть символы "–" (короткое тире) или "—" (длинное тире),
    - **то** их необходимо заменить на "-" (дефис)
    - **Если** в полях FLD-4 «Фамилия», FLD-5 «Имя», FLD-6 «Отчество» первый символ это а-я, a–z (строчная русская или английская буква),
    - **то** его необходимо заменить на соответствующий символ А-Я, A–Z (заглавную русскую или английскую букву)
