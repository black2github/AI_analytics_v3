# ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»

## 1. Назначение

ЭФ предназначена для заполнения данных заявки – [Заявка на открытие первого счета_2021](../../data-model/dictionaries.md#реестр)

**Как перейти:**

Перейти на ЭФ пользователь Клиента может:

- по кнопке "Ввести данные организации вручную" на [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md)
- автоматически:
  - **Если** [[Настраиваемые параметры] ОНБ_В](../../data-model/dictionaries.md#настраиваемые-параметры).«onboardingExternal.dadataEnabled» == FALSE,
  - **то** с [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md)
- По кнопке браузера "Вперед" с [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md)
- По кнопке браузера "Назад" с [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](scr-cl-03-applicant.md)

## 3. Видимость блоков

- «Блок выбора организации» — отображается всегда; название блока на ЭФ не отображается.
- «Блок выбора типа счёта» — отображается всегда; название блока на ЭФ не отображается.

## 4. Правила полей

### FLD-1. «Баннер MW»

- **Тип:** Гиперссылка
- **Способ заполнения:** Автоматически
- **Обязательность:** Да
- **Видимость:**
  - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» (не равно) != true **или** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«S» (не равно) != true,
  - **то** отображается в верхней части ЭФ,
  - **иначе** отображается по тапу на иконку в нижней части ЭФ
  - Данный баннер должен отображаться на всех страницах авторизации.
- **Логика установки значения:** = "Лучший цифровой банк для корпоративных клиентов<br>ТОП-1 в рейтинге Markswebb"
- **Действие:** Кликабельный баннер с информацией о рейтинге MarksWebb. По нажатию на баннер открывается модальное окно: [PLT-003 Модальное окно "Первое место в рейтинге MW"](../../platform-functions.md#plt-003-модальное-окно-первое-место-в-рейтинге-mw)

### FLD-2. «Заголовок»

- **Тип:** Заголовок
- **Способ заполнения:** Автоматически
- **Обязательность:** Да
- **Логика установки значения:** = "Открытие счёта для бизнеса"

### FLD-3. «Порядок открытия счета»

- **Тип:** Текст
- **Формат:**
  - **Отображения текста:**
    - "1", "Заявка", "Заполните заявку онлайн"
    - "2", "Встреча", "Подпишите документы на встрече"
    - "3", "Счёт открыт", "Можно пользоваться счётом"
  - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» == true
  - **то** элементы отображаются вертикально
  - **иначе** элементы отображаются горизонтально
- **Способ заполнения:** Автоматически
- **Обязательность:** Да
- **Видимость:** Название поля на ЭФ не отображается

### FLD-4. «Краткое наименование»

- **Тип:** Текст
- **Способ заполнения:**
  - Автоматически / Вручную
  - **Если** FLD-4 «Краткое наименование» не пусто и FLD-11 «ID заявки на продажу в АС CRM Infor» не пусто,
  - **то** не доступно,
  - **иначе** доступно.
- **Обязательность:** Да
- **Видимость:** Всегда отображается
- **Логика установки значения:**
  - **По умолчанию:** при переходе на ЭФ с [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md):
    - **Если** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md).«Выберите организацию» не пусто
    - **то**
      - **Если** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md).«ID заявки на продажу в АС CRM Infor» не пусто **или** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md).«ID записи сведений по заявке во внешней системе» не пусто,
      - **то** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md).«Выберите организацию»,

### FLD-7. «Город обслуживания»

- **Тип:** Список
- **Формат:**
  - **Placeholder:** Значок лупы + "Выберите из списка"
  - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» == true

  - **иначе** в виде контекстного меню
- **Способ заполнения:** Автоматически / Выбор из списка
- **Обязательность:** Да
- **Логика установки значения:**
  - **По умолчанию:** при переходе на ЭФ с [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md):
    - **=** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md).«Город обслуживания»

    - **=** [Справочник городов](../../data-model/dictionaries.md#реестр).«Населенный пункт»
    - **Дополнительные параметры отображения записей списка:**
      - Список скроллируемый
- **Поиск:** Осуществляется поиск по частичному вхождению введенного текста (поисковой строки) в значение атрибута [Справочник городов](../../data-model/dictionaries.md#реестр).«Населенный пункт»

### FLD-8. «Тип счёта»

- **Тип:** Список
- **Формат:**
  - **Placeholder:** "Выберите из списка"
  - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» == true

  - **иначе** в виде контекстного меню
- **Способ заполнения:**
  - Автоматически / Выбор из списка
  - **Если** FLD-13 «Заключение двустороннего ДБС» не пуст,
  - **то** недоступно для редактирования,
  - **иначе** доступно для редактирования
- **Обязательность:** Да
- **Логика установки значения:**
  - **По умолчанию:**
    - **Если** переход на ЭФ осуществляется с [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md),
    - **то** = [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](scr-cl-01-org-data.md).«Тип счёта»,
    - **иначе** пусто
  - **Источник списка:**
    - **На выбор предоставляются значения:**
      - **Если** [[Настраиваемые параметры] ОНБ_В](../../data-model/dictionaries.md#настраиваемые-параметры).«disableGOZ» == TRUE
      - **то**
        - "Расчётный счёт"
        - "Счёт участника закупок"
      - **иначе** ([[Настраиваемые параметры] ОНБ_В](../../data-model/dictionaries.md#настраиваемые-параметры).«disableGOZ» == FALSE)
        - "Расчётный счёт"
        - "Счёт исполнителя ГК"
        - "Счёт головного исполнителя ГК"
        - "Счёт участника закупок"

### FLD-9. «Согласен на обработку и передачу персональных данных, а также принимаю условия резервирования счёта»

- **Тип:** Чекбокс
- **Способ заполнения:** Вручную
- **Обязательность:** Да
- **Видимость:**

- **Логика установки значения:**
  - **По умолчанию:** FALSE (выключен)
- **Действие:**

  - **то** осуществляется вызов метода [PLT-002 ЭКО_Получение текста согласия](../../platform-functions.md#plt-002-эко_получение-текста-согласия) с параметром в заголовке запроса:

## 5. События

| ID | Триггер | Суть реакции |
|---|---|---|
| EV-1 | Открытие формы | Открытие ЭФ или переход по redirect url на [Профиль] ЭФ Клиента "Аутентификация по логину и паролю" по настройке сервиса; отображение введенных ранее данных при переходе кнопками браузера |
| EV-2 | Изменение FLD-5 «ИНН» (ввод/удаление 12-го символа) | Скрытие и очистка / показ FLD-6 «КПП» |


### EV-1. Открытие формы

- **Если** [[Настраиваемые параметры] ОНБ_В](../../data-model/dictionaries.md#настраиваемые-параметры).«onboardingExternal.enabled» == TRUE
- **то** ЭФ открывается и доступна пользователю в соответствии с описанной логикой
- **иначе** осуществляется переход по redirect url на [Профиль] ЭФ Клиента "Аутентификация по логину и паролю"

- **Если** переход на ЭФ осуществляется по нажатию кнопок браузера "Вперед" и "Назад",
- **то** отображать введенные ранее данные


### EV-2. Изменение FLD-5 «ИНН» (ввод/удаление 12-го символа)

- **Если** в поле FLD-5 «ИНН» введён 12-й символ,
- **то** поле FLD-6 «КПП» скрывается и **очищается**.
- **Если** в поле FLD-5 «ИНН» удалён 12-й символ,
