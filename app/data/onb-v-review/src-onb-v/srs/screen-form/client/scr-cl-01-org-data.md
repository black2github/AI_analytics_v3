# ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»

## 1. Назначение

ЭФ предназначена для заполнения данных заявки – [Заявка на открытие первого счета_2021](../../data-model/dictionaries.md#реестр)

**Как перейти:**

Перейти на ЭФ пользователь Клиента может:

- По ссылке с лендинга
- По нажатию кнопки браузера "Обновить" с [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](scr-cl-02-org-data-no-dadata.md), [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](scr-cl-03-applicant.md), [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](scr-cl-04-phone-confirm.md)
- По кнопке браузера "Назад" с [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](scr-cl-02-org-data-no-dadata.md), [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](scr-cl-03-applicant.md)
- По ссылке с Нотификации, отправленной пользователю клиента на шаге №29 процесса [ОНБ_2021] Создать / изменить заявку и отправить в банк
- По ссылке с сайта банка, раздел МСБ

## 3. Видимость блоков

- «Блок выбора организации» — отображается всегда; название блока на ЭФ не отображается.
- «Блок выбора типа счёта» — отображается всегда; название блока на ЭФ не отображается.

## 4. Правила полей

### FLD-1. «Баннер MW»

- **Тип:** Гиперссылка
- **Способ заполнения:** Автоматически
- **Обязательность:** Да
- **Видимость:**
  - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» (не равно) != true **или** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«S» (не равно) != true,
  - **то** отображается в верхней части ЭФ,
  - **иначе** отображается по тапу на иконку в нижней части ЭФ
  - Данный баннер должен отображаться на всех страницах авторизации.
- **Логика установки значения:** = "Лучший цифровой банк для корпоративных клиентов<br>ТОП-1 в рейтинге Markswebb"
- **Действие:** Кликабельный баннер с информацией о рейтинге MarksWebb. По нажатию на баннер открывается модальное окно: [PLT-003 Модальное окно "Первое место в рейтинге MW"](../../platform-functions.md#plt-003-модальное-окно-первое-место-в-рейтинге-mw)

### FLD-2. «Заголовок»

- **Тип:** Заголовок
- **Способ заполнения:** Автоматически
- **Обязательность:** Да
- **Логика установки значения:** = "Открытие счёта для бизнеса"

### FLD-3. «Порядок открытия счета»

- **Тип:** Текст
- **Формат:**
  - **Отображения текста:**
    - "1", "Заявка", "Заполните заявку онлайн"
    - "2", "Встреча", "Подпишите документы на встрече"
    - "3", "Счёт открыт", "Можно пользоваться счётом"
  - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» == true
  - **то** элементы отображаются вертикально
  - **иначе** элементы отображаются горизонтально
- **Способ заполнения:** Автоматически
- **Обязательность:** Да
- **Видимость:** Название поля на ЭФ не отображается

### FLD-4. «Выберите организацию»

- **Тип:** Поиск
- **Формат:**
  - **В поле:** **Пример:** "ООО "Солнышко"
  - **В списке:**
    - **Пример:**
      - ООО "Солнышко"
      - ИНН: 7729300400, Адрес: г. Москва, ул. Василисы Кожиной, д. 12
  - **Placeholder:** Значок лупы + "Наименование или ИНН".
- **Способ заполнения:**
  - Автоматически / Вручную / Выбор из списка
  - **Если** [CALL-INT-002 [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM](../../contract-call/internal/call-int-002-onb2021-find-request-by-crm-id.md).Исходящие параметры.«Краткое наименование клиента» не пуст и FLD-11 «ID заявки на продажу в АС CRM Infor» не пуст (см. [EV-1. Открытие формы](#ev-1-открытие-формы)),
  - **то** не доступно,
  - **иначе** доступно.
- **Обязательность:** Да
- **Логика установки значения:**
  - **По умолчанию:**
    - **Если** FLD-11 «ID заявки на продажу в АС CRM Infor» не пуст и [CALL-INT-002 [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM](../../contract-call/internal/call-int-002-onb2021-find-request-by-crm-id.md).Исходящие параметры.«Краткое наименование клиента» не пуст (см. [EV-1. Открытие формы](#ev-1-открытие-формы)),
    - **то** = [CALL-INT-002 [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM](../../contract-call/internal/call-int-002-onb2021-find-request-by-crm-id.md).Исходящие параметры.«Краткое наименование клиента»
    - **иначе если** входящие параметры.«ID заявки на сайте Банка МСБ» (idSale) не пуст **и** найдена запись сущности [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр) (см. [EV-1. Открытие формы](#ev-1-открытие-формы)),
    - **то =** [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр).«Содержимое».«Organization/Name» (см. [EV-1. Открытие формы](#ev-1-открытие-формы)),
    - **иначе** Массив "Организации".«Краткое наименование» записи, выбранной в этом поле
  - **Источник списка:**
    - **Если** [PLT-001 Метод определения размерности экрана](../../platform-functions.md#plt-001-метод-определения-размерности-экрана).«XS» == true
    - **то** список открывается в виде нижней шторки
    - **иначе** в виде контекстного меню
    - **В списке отображаются:**
      - Организации, найденные во внешних источниках (условия отображения см. в п. "Формирование списка организаций "Организации, найденные во внешних источниках" ниже)
      - Кнопка "Ввести данные организации вручную" (условия отображения см. в описании кнопки, отображается всегда в самом низу списка)
    - **Дополнительные параметры построения и отображения записей списка:**
      - Максимальное количество отображаемых (видимых на ЭФ) записей - 15
      - Список скроллируемый
      - Набор отображаемых полей в сформированном списке:
        - Массив "Организации".«Краткое наименование»;
        - Массив "Организации".«ИНН»;
        - Массив "Организации".«Адрес».
    - Формирование списка организаций "Организации, найденные во внешних источниках":
      - **Если** в поле введено не менее 2 символов **и** после ввода последнего символа прошло более 30 мс,
      - **то** осуществляется создание и заполнение массива "Организации" (см. [FF-1 «Правила формирования массива "Организации"»](#ff-1-правила-формирования-массива-организации)):
        - **Если** в массиве "Организации" есть хотя бы одна запись
        - **то** записи массива отображаются в выпадающем списке
        - **иначе** не отображаются
      - **иначе** никаких действий не выполняется
- **Поиск:** Осуществляется поиск по частичному вхождению введенного текста (поисковой строки) в значение одного или нескольких атрибутов в данных из внешних источников

  - **или** организация/ИП выбрана из сервиса подсказок в поле FLD-4 «Выберите организацию»

  - **или** входящие параметры.«ID заявки на сайте Банка МСБ» (idSale) не пуст **и** найдена запись сущности [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр) (см. [EV-1. Открытие формы](#ev-1-открытие-формы)),

    - **Если** FLD-11 «ID заявки на продажу в АС CRM Infor» не пуст **и** [CALL-INT-002 [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM](../../contract-call/internal/call-int-002-onb2021-find-request-by-crm-id.md).Исходящие параметры.«ИНН клиента» не пуст (см. [EV-1. Открытие формы](#ev-1-открытие-формы)),
    - **то** = [CALL-INT-002 [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM](../../contract-call/internal/call-int-002-onb2021-find-request-by-crm-id.md).Исходящие параметры.«ИНН клиента»,
    - **иначе если** входящие параметры.«ID заявки на сайте Банка МСБ» (idSale) не пуст **и** найдена запись сущности [Сведения для создания заявки на открытие первого счета из внешней системы](../../data-model/dictionaries.md#реестр),

- Массив "Организации".«ИНН»
- Массив "Организации".«КПП» (заполняется для ЮЛ)
- Массив "Организации".«Адрес»
- Массив "Организации".«Город регистрации»
- Массив "Организации".«Фамилия» (заполняется для ИП)
- Массив "Организации".«Имя» (заполняется для ИП)
- Массив "Организации".«Отчество» (заполняется для ИП)

После выполнения операции осуществляется переход на шаг №2.

**Шаг 2.** Осуществляется вызов метода [PLT-004 Сервис подсказки по организациям и ИП](../../platform-functions.md#plt-004-сервис-подсказки-по-организациям-и-ип), входящие параметры заполняются следующим образом:

- query = текст в поле FLD-4 «Выберите организацию»
- count = "15"
- **Если** метод выполнен без ошибок (в ответ на вызов метода получен код 200)
- **то** осуществляется переход на шаг 3
- **иначе** осуществляется переход на шаг 4

**Шаг 3.** Из ответа метода, вызванного на шаге №2 , извлекаются все блоки массива **suggestions**. Каждый блок - информация об одной организации. Осуществляется заполнение массива для каждой организации по следующей логике:

- Массив "Организации".«Краткое наименование» = **suggestions/value**
- Массив "Организации".«ИНН» = **suggestions/data/inn**
- Массив "Организации".«КПП» = **suggestions/data/kpp**
- Массив "Организации".«Адрес» = **suggestions/data/address/value**
- Массив "Организации".«Город регистрации» = **suggestions/data/address/data/city_with_type**
- Массив "Организации".«Фамилия» = **suggestions/data/fio/surname**
- Массив "Организации".«Имя» = **suggestions/data/fio/name**
- Массив "Организации".«Отчество» = **suggestions/data/fio/patronymic**

**Шаг 4.** Процесс завершен.
