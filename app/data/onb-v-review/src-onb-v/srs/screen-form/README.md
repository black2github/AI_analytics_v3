# Экранные формы

Экранные формы (ЭФ) сервиса — интерфейсы Клиента во внешней части сайта. Формы сгруппированы по контурам; у сервиса есть формы только клиентского контура.

## Клиентский контур

Реестр форм — [client/README.md](client/README.md).

## Платформенные экраны

Универсальное модальное окно рейтинга MarksWebb — [PLT-003 Модальное окно "Первое место в рейтинге MW"](../platform-functions.md#plt-003-модальное-окно-первое-место-в-рейтинге-mw).

## Как читать экранную форму

ЭФ описаны событийной моделью:

- **EV-N — событие**: открытие формы или реакция на изменение поля.
- **B-N — кнопка**: элемент управления и логика нажатия.
- **FLD-N — правило поля**: статика (тип, формат, заполнение, обязательность, видимость).
- **MSG-N — сообщение**: текст, показываемый пользователю.
- **FF-N — функция формы**: именованный набор шагов этой формы (массив «Организации»).

Проверки полей — в [контролях](../control/README.md). Параметры — в [справочниках](../data-model/dictionaries.md).
