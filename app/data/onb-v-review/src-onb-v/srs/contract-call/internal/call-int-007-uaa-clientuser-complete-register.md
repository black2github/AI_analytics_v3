# CALL-INT-007. uaa/clientuser/completeRegister - Завершение регистрации пользователя

**Базовый контракт:** uaa/clientuser/completeRegister - Завершение регистрации пользователя — постановка владельца (UAA) вне комплекта.

## Назначение

Сервис вызывает uaa/clientuser/completeRegister - Завершение регистрации пользователя (метод платформенного сервиса UAA), чтобы завершить регистрацию по СМС-коду с ЭФ подтверждения номера телефона.

## Использование в сервисе «Открытие 1-го счета и регистрация во внешней части сайта»

### Процессы

- [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](../../screen-form/client/scr-cl-04-phone-confirm.md), кнопка "Условное продолжить": вызов и обработка исходящих.
- [PROC-001 Открытие счета с внешнего сайта](../../process/proc-001-open-account-from-external-site.md), шаги 1.14, 2.8: вызов метода (подробное описание вызова и обработки исходящих — на [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](../../screen-form/client/scr-cl-04-phone-confirm.md)).

### Транспорт

Синхронный HTTP-запрос.

### Правила заполнения исходящего сообщения

| Параметр контракта | Правило сервиса |
|---|---|
| «Метод регистрации» | `"EXTERNAL_SITE"` |
| «Идентификатор запроса на регистрацию» | исходящие параметры метода [CALL-INT-006 uaa/clientuser/register - Первоначальная регистрация пользователя](call-int-006-uaa-clientuser-register.md).«Идентификатор запроса на подтверждение», вызванного на [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](../../screen-form/client/scr-cl-03-applicant.md) |
| «СМС-код подтверждения регистрации» | [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](../../screen-form/client/scr-cl-04-phone-confirm.md#fld-4-код-подтверждения).«Код подтверждения» |
| «Уникальный идентификатор приложения в IDP» | Уникальный идентификатор приложения в IDP в соответствии со справочником "[Справочник доверенных систем](../../data-model/dictionaries.md#реестр)" |

### Обработка входящих ответов

| Параметр контракта | Правило сервиса |
|---|---|
| «Системный код ошибки» | **Если** исходящие параметры метода содержат uaa/clientuser/completeRegister - Завершение регистрации пользователя.«Системный код ошибки»,<br>**то** выводится сообщение об ошибке, соответствующее значению кода, полученного в исходящих параметрах метода uaa/clientuser/completeRegister - Завершение регистрации пользователя.«Системный код ошибки», переход на шаг 3.<br>**иначе** переход на шаг 2 (редирект на [ОНБ_2021] ЭФ Клиента "Выбор организации/ИП" в режиме создания) |
