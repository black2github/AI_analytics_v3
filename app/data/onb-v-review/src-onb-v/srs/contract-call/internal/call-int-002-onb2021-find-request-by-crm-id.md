# CALL-INT-002. [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM

**Базовый контракт:** [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM — постановка владельца (сервис ОНБ_2021) вне комплекта.

## Назначение

Сервис вызывает [ОНБ_2021] Метод поиска заявки ОНБ по идентификатору CRM (метод сервиса Экосистемы ОНБ_2021) при открытии ЭФ ввода организации/ИП, если в redirect url передан идентификатор CRM, чтобы найти заявку ОНБ и автоматически заполнить поля ЭФ.

## Использование в сервисе «Открытие 1-го счета и регистрация во внешней части сайта»

### Процессы

[SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](../../screen-form/client/scr-cl-01-org-data.md), [EV-1. Открытие формы](../../screen-form/client/scr-cl-01-org-data.md#ev-1-открытие-формы), шаг 2; исходящие параметры метода используются в логике автоматического заполнения и доступности полей ЭФ («Выберите организацию», «ИНН», «КПП», «Тип счёта», «ID заявки на продажу в АС CRM Infor»).

### Транспорт

Синхронный HTTP-запрос.

### Правила заполнения исходящего сообщения

Вызов выполняется, **если** входящие параметры.«ID сквозной для CRM infor» (передается в redirect url в параметре "externalId") не пуст.

| Параметр контракта | Правило сервиса |
|---|---|
| — | входящие параметры.«ID сквозной для CRM infor» (redirect url: параметр "externalId") |
