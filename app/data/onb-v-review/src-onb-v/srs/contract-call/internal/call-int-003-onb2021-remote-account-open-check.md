# CALL-INT-003. [ОНБ_2021] Метод проверки возможности удалённого открытия счёта

**Базовый контракт:** [ОНБ_2021] Метод проверки возможности удалённого открытия счёта — постановка владельца (сервис ОНБ_2021) вне комплекта.

## Назначение

Сервис вызывает [ОНБ_2021] Метод проверки возможности удалённого открытия счёта (метод сервиса Экосистемы ОНБ_2021), чтобы проверить возможность удалённого открытия счёта по идентификатору заявки и признаку согласия.

## Использование в сервисе «Открытие 1-го счета и регистрация во внешней части сайта»

### Процессы

- [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](../../screen-form/client/scr-cl-01-org-data.md) и [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](../../screen-form/client/scr-cl-02-org-data-no-dadata.md): кнопка "Открыть счёт", если [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](../../screen-form/client/scr-cl-01-org-data.md#fld-12-удаленное-открытие-счета).«Удаленное открытие счета» или [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](../../screen-form/client/scr-cl-02-org-data-no-dadata.md#fld-12-удаленное-открытие-счета).«Удаленное открытие счета» не пусто.
- [PROC-001 Открытие счета с внешнего сайта](../../process/proc-001-open-account-from-external-site.md), шаг №1а: **если** в url параметр "roid" передан и не пуст.

### Транспорт

Синхронный HTTP-запрос.
