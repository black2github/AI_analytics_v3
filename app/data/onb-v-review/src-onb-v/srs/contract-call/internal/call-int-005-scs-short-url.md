# CALL-INT-005. [СКС] Метод генерации коротких ссылок

**Базовый контракт:** [СКС] Метод генерации коротких ссылок — постановка владельца (сервис СКС) вне комплекта.

## Назначение

Сервис вызывает [СКС] Метод генерации коротких ссылок (метод платформенного сервиса СКС) на шаге №2а процесса открытия счёта с внешнего сайта и при нажатии «Открыть счёт» на ЭФ ввода данных организации/ИП, чтобы получить короткий код URL для редиректа на регистрацию.

## Использование в сервисе «Открытие 1-го счета и регистрация во внешней части сайта»

### Процессы

- [PROC-001 Открытие счета с внешнего сайта](../../process/proc-001-open-account-from-external-site.md), шаг №2а (после шага №1а, если сведения о физическом лице, пожелавшем открыть счет удаленно, найдены).
- [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](../../screen-form/client/scr-cl-01-org-data.md) и [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](../../screen-form/client/scr-cl-02-org-data-no-dadata.md): кнопка "Открыть счёт", шаг 2, **если** «Код ответа» [CALL-INT-003 [ОНБ_2021] Метод проверки возможности удалённого открытия счёта](call-int-003-onb2021-remote-account-open-check.md) == `"AVAILABLE"`.

### Транспорт

Синхронный HTTP-запрос. Редирект после ответа: url = `"https://passport.gbo.gazprombank.ru/registration/"` + «Код короткого URL».
