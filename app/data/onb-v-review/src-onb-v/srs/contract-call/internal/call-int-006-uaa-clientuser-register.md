# CALL-INT-006. uaa/clientuser/register - Первоначальная регистрация пользователя

**Базовый контракт:** uaa/clientuser/register - Первоначальная регистрация пользователя — постановка владельца (UAA) вне комплекта.

## Назначение

Сервис использует uaa/clientuser/register - Первоначальная регистрация пользователя (метод платформенного сервиса UAA) как шаг №4 процесса [Профиль] Процесс регистрации пользователя Клиента: первоначальная регистрация пользователя и отправка СМС с кодом подтверждения.

## Использование в сервисе «Открытие 1-го счета и регистрация во внешней части сайта»

### Процессы

- [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](../../screen-form/client/scr-cl-03-applicant.md), кнопка "Продолжить", шаг 2: выполняется шаг №4 процесса [Профиль] Процесс регистрации пользователя Клиента.
- [PROC-001 Открытие счета с внешнего сайта](../../process/proc-001-open-account-from-external-site.md), шаг 1.10 (Шаг №3а): выполняется шаг №4 процесса [Профиль] Процесс регистрации пользователя Клиента.
- Исходящий «Идентификатор запроса на подтверждение» потребляется вызовами [CALL-INT-007 uaa/clientuser/completeRegister - Завершение регистрации пользователя](call-int-007-uaa-clientuser-complete-register.md) и [CALL-INT-008 uaa/clientuser/renewConfirm - Повторная отправка кода подтверждения](call-int-008-uaa-clientuser-renew-confirm.md) на [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](../../screen-form/client/scr-cl-04-phone-confirm.md).

### Транспорт

Синхронный HTTP-запрос.

### Правила заполнения исходящего сообщения

| Параметр контракта | Правило сервиса |
|---|---|
| — | вызывается как шаг №4 процесса [Профиль] Процесс регистрации пользователя Клиента |

### Обработка входящих ответов

| Параметр контракта | Правило сервиса |
|---|---|
| «Системный код ошибки» | по результатам шага №4 процесса регистрации:<br>**Если** запрос выполнен успешно и СМС с кодом подтверждения отправлен пользователю,<br>**то** переход на шаг №3 кнопки "Продолжить" (ЭФ подтверждения номера телефона).<br>**иначе** (исходящие параметры метода uaa/clientuser/register - Первоначальная регистрация пользователя.«Системный код ошибки» == 911) пользователь остается на ЭФ, для [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](../../screen-form/client/scr-cl-03-applicant.md#fld-9-капча-ввод).«Капча (ввод)» выводится сообщение об ошибке "Неверный код", переход на шаг №4 |
| «Идентификатор запроса на подтверждение» | исходящий параметр, передаваемый в [CALL-INT-007 uaa/clientuser/completeRegister - Завершение регистрации пользователя](call-int-007-uaa-clientuser-complete-register.md) («Идентификатор запроса на регистрацию») и [CALL-INT-008 uaa/clientuser/renewConfirm - Повторная отправка кода подтверждения](call-int-008-uaa-clientuser-renew-confirm.md) («Идентификатор запроса на подтверждение») |
| confirmationRequest.lifeTime | время жизни текущей попытки кода подтверждения (в секундах) — отсчёт FLD-5 «Таймер» на [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](../../screen-form/client/scr-cl-04-phone-confirm.md) |
