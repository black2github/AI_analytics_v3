# Вызовы контрактов

**Здесь — только то, КАК этот сервис вызывает интерфейсы, которыми владеют другие**: назначение вызова, процессы и шаги, транспорт, правила заполнения запросов и обработка ответов. Вызываемым может быть внешняя АС банка, метод другого сервиса Экосистемы или платформенный метод со спецификацией — карточка вызова устроена одинаково, различается владелец контракта.

**Описаний самих интерфейсов здесь НЕТ** — базовый контракт (паспорт метода, структура параметров, коды результата, примеры) живёт у владельца:

- внешняя АС банка — репозиторий docs-external-contracts (ID вида `EXTINT-<AS>-NNN`);
- другой сервис Экосистемы — `internal-contract/` его комплекта (ID вида `INTC-NNN`);
- платформенный метод со спецификацией — документация платформы.

Чего здесь тоже нет: контракты собственных методов сервиса — `internal-contract/` комплекта вызываемого сервиса; платформенные функции БЕЗ опубликованной спецификации — записи `PLT-NNN` в [`platform-functions.md`](../platform-functions.md).
