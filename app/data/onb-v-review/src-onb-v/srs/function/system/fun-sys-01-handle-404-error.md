# Функция обработки ошибки 404

## 1. Назначение

Обрабатывает ошибку 404, возникающую при переходе по url (ссылке) любой страницы Сервиса, — перенаправляет пользователя по redirect url на ЭФ ввода данных организации/ИП.

## 2. Доступность

Системная функция; роли и привилегии не применяются

## 3. Вызов функции

Данная функция вызывается:

- **Если** при переходе по url (ссылке) любой страницы Сервиса [[ОНБ_В] Сервис открытия 1-го счета и регистрации клиента во внешней части сайта](../../../README.md) возвращается ошибка 404 (сервер не может найти страницу, запрошенную пользователем)

## 5. Поведение

При вызове данной функции:

- Осуществляется переход по redirect url на [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](../../screen-form/client/scr-cl-01-org-data.md)
