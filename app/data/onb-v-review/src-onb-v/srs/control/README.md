# Контроли ввода данных организации и заявителя

## 1. Назначение

Система автоматически проверяет поля экранных форм при нажатии кнопки "Открыть счёт" (ввод данных организации/ИП) и кнопки "Продолжить" (ввод данных заявителя). Непройденный контроль блокирует переход и показывает сообщение об ошибке на поле.

Тип контроля — Жесткий (ввод организации/ИП) и Жесткая (ввод заявителя); мягких и отключённых нет. Проверка осуществляется только на front; back-контроли отсутствуют.

## 2. Группы контролей

Нет данных из DADATA»](../screen-form/client/scr-cl-02-org-data-no-dadata.md); [PROC-001 Открытие счета с внешнего сайта](../process/proc-001-open-account-from-external-site.md) |
| CTL-GRP-2 | При нажатии кнопки "Продолжить" | [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](../screen-form/client/scr-cl-03-applicant.md); [PROC-001 Открытие счета с внешнего сайта](../process/proc-001-open-account-from-external-site.md) |

На ЭФ сообщения об ошибке выводятся на конкретном поле, поэтому <Название реквизита> не указывается в тексте. Например, "Обязательное поле". `<Название реквизита>` — наименование проверяемого поля на ЭФ; `<список найденных недопустимых символов>` — недопустимые символы, найденные в значении реквизита.
