# Платформенные функции и проверки

## 1. Назначение

Реестр **платформенных функций, проверок и универсальных экранов** платформы ЭКО, которые сервис вызывает, но **не реализует сам**. Нужен, чтобы ссылаться на такие точки из экранных форм, функций и процессов по стабильному идентификатору.

Отграничение от смежных артефактов:

- **не CALL-INT** — карточки [вызовов контрактов](contract-call/README.md) описывают методы со спецификацией (`CALL-INT`, каталог [`internal/`](contract-call/internal/README.md)); записи `PLT` — функции, проверки и универсальные экраны платформы без опубликованной спецификации;
- **не CTL** — [контроли](control/README.md) проверяют данные заявки внутри сервиса; PLT выполняет платформа;
- **не FUN** — функции сервиса реализует сам микросервис; PLT сервис только вызывает. Карточки функций — в [function/README.md](function/README.md).

## 3. Карточки

### PLT-001. Метод определения размерности экрана

- **Тип:** функция (платформа).
- **Назначение:** определяет размерность экрана пользователя; сервис сравнивает исходящие «XS» и «S» с `true` для видимости блоков, раскладки шагов и вида модальных окон (нижняя шторка / модальное окно / контекстное меню).
- **Где используется:** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](screen-form/client/scr-cl-01-org-data.md) — FLD-1 «Баннер MW», FLD-3 «Порядок открытия счета», FLD-4 «Выберите организацию», FLD-7 «Город обслуживания», FLD-8 «Тип счёта», FLD-9 «Согласен на обработку и передачу персональных данных, а также принимаю условия резервирования счёта», B-2 «Открыть счёт», B-3 «Войти в ГПБ Бизнес-Онлайн»; [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](screen-form/client/scr-cl-02-org-data-no-dadata.md) — FLD-1 «Баннер MW», FLD-3 «Порядок открытия счета», FLD-7 «Город обслуживания», FLD-8 «Тип счёта», FLD-9 «Согласен на обработку и передачу персональных данных, а также принимаю условия резервирования счёта», B-1 «Открыть счёт», B-2 «Войти в ГПБ Бизнес-Онлайн»; [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](screen-form/client/scr-cl-03-applicant.md) — FLD-1 «Баннер MW», FLD-12 «Согласен на обработку и передачу персональных данных, а также принимаю условия резервирования счёта», B-3 «Войти в ГПБ Бизнес-Онлайн»; [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](screen-form/client/scr-cl-04-phone-confirm.md) — FLD-1 «Баннер MW», B-1 «Войти в ГПБ Бизнес-Онлайн», B-4 «Назад». Из ответа используются «XS» и «S» (сравнение с `true`).

### PLT-002. ЭКО_Получение текста согласия

- **Тип:** функция (платформа).
- **Назначение:** по клику на ссылку «персональных данных» сервис вызывает ЭКО_Получение текста согласия и передаёт код локали в заголовке запроса.
- **Где используется:** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](screen-form/client/scr-cl-01-org-data.md) — FLD-9 «Согласен на обработку и передачу персональных данных, а также принимаю условия резервирования счёта»; [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](screen-form/client/scr-cl-02-org-data-no-dadata.md) — FLD-9 «Согласен на обработку и передачу персональных данных, а также принимаю условия резервирования счёта»; [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](screen-form/client/scr-cl-03-applicant.md) — FLD-12 «Согласен на обработку и передачу персональных данных, а также принимаю условия резервирования счёта» — если пользователь кликнул по ссылке «персональных данных». Входящий параметр в заголовке запроса: «Locale-code» = [[Локализация] Параметры браузера](data-model/dictionaries.md#реестр).«eco_locale».

### PLT-003. Модальное окно "Первое место в рейтинге MW"

- **Тип:** экран (платформа).
- **Назначение:** универсальное платформенное модальное окно рейтинга MarksWebb; открывается по нажатию на кликабельный баннер.
- **Где используется:** FLD-1 «Баннер MW» на [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](screen-form/client/scr-cl-01-org-data.md), [SCR-CL-02 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта. Нет данных из DADATA»](screen-form/client/scr-cl-02-org-data-no-dadata.md), [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](screen-form/client/scr-cl-03-applicant.md), [SCR-CL-04 ЭФ Клиента «Подтверждение номера телефона»](screen-form/client/scr-cl-04-phone-confirm.md) — по нажатию на баннер открывается модальное окно "Первое место в рейтинге MW".

### PLT-004. Сервис подсказки по организациям и ИП

- **Тип:** функция (платформа).
- **Назначение:** по тексту, введённому в поле «Выберите организацию», возвращает подходящие организации и ИП; из ответа сервис формирует массив "Организации", а ОГРН из ответа передаёт на определение профиля клиента.
- **Где используется:** [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](screen-form/client/scr-cl-01-org-data.md) (FF-1 «Правила формирования массива "Организации"», шаги 2–3); [PROC-001 Открытие счета с внешнего сайта](process/proc-001-open-account-from-external-site.md) (шаг 1.9.1)
