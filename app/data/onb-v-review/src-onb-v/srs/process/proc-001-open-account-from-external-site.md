# PROC-001. Открытие счета с внешнего сайта

## Назначение

Сквозной процесс сервиса: от нажатия кнопки "Открыть счёт" на лендинге или перехода по ссылке-приглашению из электронной почты — до создания заявки на открытие первого счёта, авторизации пользователя или ухода пользователя со страницы.

- **Роль:** корневой процесс.
- **Инициатор:** Пользователь Клиента.
- **Исполнители:** Система; Пользователь Клиента — шаги 1.1, 1.2, 1.6, 1.12, 1.18.
- **Предусловие:**
  - Пользователь нажал кнопку "Открыть счёт" на лендинге
  - или Пользователь перешел по ссылке-приглашению из электронной почты
- **Исходы:** «Осуществляется редирект на url» (шаг 1.10, успех), «Инициирована авторизация пользователя. Процесс завершен» (успех), «Процесс завершен» (шаг 2.12.3, успех), «Создана заявка на открытие первого счета. Процесс завершен» (успех), «Пользователь покинул страницу. Процесс завершен» и «Авторизация не пройдена. Процесс завершен» — см. [Исходы процесса](#исходы-процесса).
- **Нумерация шагов:** `1.x` — основной маршрут пользователя; `2.x` — первоначальная регистрация, код подтверждения, завершение регистрации, авторизация и маршрутизация; `3.x` — создание заявки.

Вызовы методов комплекта — по карточкам [CALL-INT-002…008](../contract-call/internal/README.md); проверки данных — по группам контролей [CTL-GRP-1 При нажатии кнопки "Открыть счёт"](../control/README.md#2-группы-контролей) и [CTL-GRP-2 При нажатии кнопки "Продолжить"](../control/README.md#2-группы-контролей).

## Детали шагов

### Начальное событие (шаг 1.1)

- **Предусловие:**
  - Пользователь нажал кнопку "Открыть счёт" на лендинге
  - или Пользователь перешел по ссылке-приглашению из электронной почты
- Осуществляется переход на шаг 1.2

### Заполнить ЭФ “Ввод данных организации/ИП с внешнего сайта” (шаг 1.2)

- Пользователь вводит данные организации на [SCR-CL-01 ЭФ Клиента «Ввод данных организации/ИП с внешнего сайта»](../screen-form/client/scr-cl-01-org-data.md)
- Пользователю доступны следующие действия, влияющие на процесс:
  - **Если** пользователь покинул страницу,
  - **то** осуществляется переход на шаг 1.18
  - **Если** пользователь нажал кнопку "Открыть счёт",
  - **то** осуществляется переход на шаг 1.4
  - **Если** пользователь нажал на кнопку "Войти в ГПБ Бизнес-Онлайн",
  - **то** осуществляется переход на шаг 1.16

### Проверить введенные данные на ЭФ “Ввод данных организации/ИП с внешнего сайта” (шаг 1.4)

- Выполняются контроли [CTL-GRP-1 При нажатии кнопки "Открыть счёт"](../control/README.md#2-группы-контролей)
- **Если** контроли пройдены успешно,
- **то:**
  - **если** в url параметр "roid" передан и не пуст,
  - **то** осуществляется переход на шаг 1.10,
  - **иначе** (в url параметр "roid" не передан или пуст) осуществляется переход на шаг 1.6,
- **иначе** осуществляется переход на шаг 1.2

### Заполнить ЭФ “Ввод данных заявителя с внешнего сайта” (шаг 1.6)

- Пользователь вводит свои данные на [SCR-CL-03 ЭФ Клиента «Ввод данных заявителя с внешнего сайта»](../screen-form/client/scr-cl-03-applicant.md)
- Пользователю доступны следующие действия, влияющие на процесс:
  - **Если** пользователь покинул страницу,
  - **то** осуществляется переход на шаг 1.18
