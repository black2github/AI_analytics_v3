# Открытие 1-го счета и регистрация во внешней части сайта

Документация сервиса **«[ОНБ_В] Сервис открытия 1-го счета и регистрации клиента во внешней части сайта»** (кодовое имя onboarding-external) — одного из сервисов АС Экосистема.

**С чего начать.** Что из себя представляет сервис, кому он нужен, какие у него границы и как устроены клиентская и банковская части — в [концепции сервиса (Service Vision)](service-vision.md). Термины и смежные системы — в [глоссарии](glossary.md).

## О сервисе (кратко)

Сервис обеспечивает открытие первого счета и регистрацию клиента во внешней части сайта. Пользователь переходит с лендинга (кнопка «Открыть счёт») или по ссылке-приглашению из электронной почты, заполняет данные организации/ИП и заявителя, подтверждает номер телефона.

У сервиса два пользовательских контура:

| Контур | Кто | Что делает |
|--------|-----|------------|
| **Клиентский (CL)** | Пользователь внешней части сайта | Заполняет данные организации/ИП и заявителя, подтверждает номер телефона |
| **Банковский (BNK)** | — | Банковской части у сервиса нет |

Между ними работает автоматическая обработка (системный актор **SYS**), в том числе функция обработки ошибки 404. Подробнее — в [Service Vision](service-vision.md#клиентская-и-банковская-части).

## О комплекте

Это чистовой комплект аналитической документации. Он самодостаточен: описывает поведение системы на уровне требований, не ссылаясь на внешние источники.

- **Формат** — Markdown, docs-as-code: документы дробятся на карточки с устойчивыми идентификаторами (`F-`, `US-`, `BR-`, `UC-`, `SCR-`, `FUN-`, `CTL-`, `PROC-`, `CALL-`, `PLT-`, `EXT-`), связанными сквозными ссылками.
- **Идентификаторы и трассировка.** Каждый артефакт имеет стабильный ID; сквозные связи сведены в [матрицу трассировки](traceability-matrix.md) — она общая для всего комплекта.
- **Навигация.** В каждом каталоге есть `README.md` — обзор раздела и реестр его артефактов.

## Условные обозначения

Карта префиксов и суффиксов в идентификаторах комплекта.

### Контуры (суффиксы в ID)

| Код | Значение | Где встречается |
|-----|----------|-----------------|
| **CL** | Клиентский контур | `F-CL-*`, `FUN-CL-*`, `SCR-CL-*`; каталоги `client/` |
| **BNK** | Банковский контур | `F-BNK-*`, `FUN-BNK-*`, `SCR-BNK-*`; каталоги `bank/` |
| **SYS** | Системные функции (без пользовательского UI) | `FUN-SYS-*`; каталог `function/system/` |

### Типы артефактов (префиксы ID)

| Префикс | Что обозначает | Где лежит |
|---------|----------------|-----------|
| **VIS** | Концепция сервиса | `service-vision.md` |
| **F-CL** | Спецификация фичи (BRD) | `brd/features/` |
| **US / FR** | User Story, функциональное требование | внутри фич |
| **UC** | Сквозной сценарий (use case) | `brd/use-cases/` |
| **BR / ТР** | Бизнес-правило / таблица решений | `brd/business-rules.md` |
| **PROC** | Процесс | `srs/process/` |
| **EXT** | Справочник / сущность платформы или другого сервиса (вне сервиса) | `srs/data-model/dictionaries.md` |
| **FUN** | Функция системы | `srs/function/` |
| **SCR** | Экранная форма | `srs/screen-form/` |
| **CTL / CTL-GRP** | Контроль / группа контролей | `srs/control/` |
| **CALL** | Вызов чужого контракта (внешняя АС, другой сервис Экосистемы, платформенный метод со спецификацией) | `srs/contract-call/` |
| **PLT** | Платформенная функция ЭКО | `srs/platform-functions.md` |

Внутри экранных форм дополнительно: **FLD-N** — правило поля, **EV-N** — событие, **B-N** — кнопка, **MSG-N** — сообщение, **FF-N** — функция формы.

## Границы комплекта

- Описывается сервис открытия 1-го счёта и регистрации клиента во внешней части сайта (кодовое имя onboarding-external).
- Концепция сервиса ([service-vision.md](service-vision.md)) и [глоссарий](glossary.md) реконструированы из SRS (reverse-from-SRS).
- BRD-слой реконструирован из SRS (reverse-from-SRS) — каталог `brd/`.
- Сущностей модели данных (`ENT`) в комплекте нет; справочники и настраиваемые параметры — в `dictionaries.md`.
- Банковской части у сервиса нет.
- Версия функциональности — `prod-2026-09`.
