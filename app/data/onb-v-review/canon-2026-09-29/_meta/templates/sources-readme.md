## Разметка подсервисов (только крупный сервис из подсервисов, conventions §3.1)

Таблица-декларация: предлагает планировщик по дереву/тегам выгрузки,
утверждает аналитик; соответствие «источник → путь» проверяет selfcheck.
Матчер — тег-префикс титула (`[КК_ЛК]`) ИЛИ имя верхнеуровневой ветви
выгрузки; первая подошедшая строка выигрывает. Зоны: `подсервис <слаг>`,
`core <слаг>` (то же + порядок миграции раньше зависимых), `общая часть`,
`вне Экосистемы` (в docs/ не размещается — мини-комплект, паспорт границы).

| Матчер (тег или ветвь) | Зона |
|---|---|
| [КК_ЛК] | подсервис limits |
| [КК_QR] | core qr-out |
| [КК_CLNT] | общая часть |
| [КК_Виджет_ПИН] | вне Экосистемы |
