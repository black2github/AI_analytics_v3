# Владельцам docs-digital-ruble: CODEOWNERS домена — у комплектов нет строки на каталог, гейт даёт ⚠ CORE-04

Дата: 2026-10-28. От владельца канона. Заметка по следам исправления гейта переноса (срез канона `f0e1ff2`).

Гейт переноса теперь читает `CODEOWNERS` из корня доменного репозитория, а не из каталога комплекта (так его
читает GitLab). На ветке домена `docs-digital-ruble` по комплекту `digital-ruble-payment` это меняет
✗ CORE-04 «CODEOWNERS отсутствует» на ⚠: в корневом файле четыре секции (Analytics, Backend, Frontend, QA), и в
каждой комплект покрыт только правилом по умолчанию `*` — владелец формально назначен, но не по каталогу.
SDLC-07 по манифесту корня — ✓ (раньше ⚠ за отсутствие манифеста в каталоге комплекта).

Что сделать: добавить в секцию аналитики строки на каталоги комплектов домена
(`/digital-ruble-payment/ @…` и т. д.) — тогда CORE-04 станет ✓ с указанием правила и владельцев. Остальные
секции — на усмотрение их владельцев. Подкаталожные `CODEOWNERS` внутри комплектов заводить не нужно: GitLab их
не читает, гейт их не засчитывает.
