# Списки дозаходов по дельте 0e32b01 — карточки по типу и категории (шаг 1.5 плана)

Дата: 2026-10-25. Источник — приложение 24.10 (вердикт утилиты переноса по страницам-источникам); категория карточки — самая строгая из её страниц; тип — `type` во frontmatter карточки. Карточки категории «только разметка» в дозаходы не входят (прибор подтверждает пустой дифф ПРОМ-среза). Категория «дополнен текст» — заход без снятий, приёмка прибором. «Изменён текст» — заходы по группам, один промпт на группу; вход каждого захода: дифф ПРОМ-среза 717b11f→0e32b01 по страницам карточек и список недоснятий из отчёта по архиву raw (шаг 1.2 — будет приложен отдельно). Карточки SCR-CL-19/20 входят в ISS-03-R2 (фаза 2), в группу screen-form не повторяются.
