## 1. Признак контура

Строка таблицы «Разметка подсервисов» профиля источников: `| <матчер> | вне Экосистемы <слаг> |`. У КК сегодня четыре строки с зоной `вне Экосистемы` без слага (`[КК_Виджет_ПИН]`, `[КК_Виджет_РЕКВ]`, `[КК_Виджет]`, `[КК]-Виджеты`, файл `README.md` корня src) — все получают `вне Экосистемы widgets-rtl`. Регулярное выражение прибора (`source_profile.py:25`, `вне Экосистемы.*`) хвост уже допускает: строка без слага остаётся распознаваемой, но прибор после С2 требует слаг (⚠ «зона без слага каталога»).

Из признака выводится: каталог части `docs/srs/<слаг>/`; все остальные решения — по штатным правилам сервиса (ID, README-реестры, матрица). У сервиса без подсервисов таблица из одной строки объявляет только часть вне Экосистемы, остальной комплект — корень `srs/` (правило `create-artifact`: «без таблицы сегмент не используется» уточняется до «сегмент только у строк таблицы»).

Шаблон паспорта в worktree написан под (а); при (б) §7 возвращается к форме §8 README.

**Р-7. ID паспорта границы.** (а) **Рекомендация:** `BND-000` (у сервиса с кодами частей в ID — `BND-<КОД>-000`, у домена — слот сервиса), по образцу однофайловых слотов `SM-000`; строка **BND** в таблице префиксов `docs-readme.md`; тип `module-passport` объявляется в README комплекта (TRF-04, как INTC/SM). ## 9. Текст для техбука conventions §3.1 (владелец)

> **Часть сервиса вне контура Экосистемы.** Модуль сервиса, исполняемый вне контура Экосистемы (устройство пользователя, канал другой системы), — часть сервиса в штатной раскладке `docs/srs/<слаг>/` теми же типами документов.
