# План завершения миграции ПРОМ-среза КК

Составлен: 2026-10-25. Ведёт владелец канона; статусы обновляются на каждой вехе.
Дом плана на время работы — этот файл (analyzer `app/data`); при передаче команде — копия в
`coordination-state.md` КК разделом «План миграции ПРОМ-среза».

## Цель плана

Довести комплект КК до состояния, в котором миграция ПРОМ-среза завершена, и перенести его
в чистовое пространство EAN. Успешное завершение миграции ПРОМ-среза означает выполнение условий (далее - Условия) ниже:

1. каждая карточка соответствует одному срезу источника — `sources/confluence` на коммите 0e32b01 —
   или несёт явный долг;
2. гейт формы проходит;
3. открытые вопросы, не влияющие на ПРОМ-текст, переведены в долги, остальные отвечены;
4. аналитики провели финальную приёмку и доводку содержания;
5. после завершения плана Confluence меняется только вводом задач: перевыгрузка страниц задачи → apply → тег
   `src/<ID>` → дельта-заход по `confluence_page_ids`.

Каждый шаг ниже ведёт к одному из этих пяти условий; столбец «Цель» называет, к какому и зачем.

## Как читать

- **Статус**: `✓` сделано · `▶` в работе · `☐` предстоит · `⏸` ждёт решения · `✗` снято.
- **Акцепт** — ручное участие аналитика: `ДА` — аналитик читает и подтверждает содержание;
  `орг.` — ручное участие есть, но это не проверка аналитики (решение, передача документа);
  `нет` — человек не нужен или получает только отчёт.
- **Исполнитель** — роль из таблицы ниже; если ролей две, указано, кто что делает.

## Роли

Роли названы по действующему порядку работы команды (канон: `prompt-coordinator.md`,
`prompt-reviewer.md`): координатор ставит заход, планировщик формирует промпты, исполнители делают
заходы по промптам, ревьюер проверяет содержание в отдельном запуске, акцептующий принимает.

| Роль | Что делает в плане |
|---|---|
| владелец канона | решения по плану, нормы канона, прибор, разбор дельты, тексты команде, выгрузка и ввод задач |
| прибор | утилиты канона без участия человека: selfcheck, critic, гейт переноса, отчёт дельты, сторож по архиву raw |
| координатор КК | ведёт журнал координации, план, опись; формирует или заказывает промпты заходов; запускает ревьюера; принимает заходы по форме; ставит OQ |
| планировщик | формирует промпты заходов по плану и постановкам |
| исполнитель | делает заход или дозаход по промпту |
| ревьюер | проверяет содержание карточек по Д-48, отчёт — координатору |
| акцептующий КК | аналитик команды, принимающий содержание карточек |
| аналитики КК | авторы требований КК; отвечают на OQ, делают доводку перед переносом |

Сводка ручных шагов — в конце файла.
