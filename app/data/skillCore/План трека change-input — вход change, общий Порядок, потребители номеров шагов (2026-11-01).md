## Цель

Текст диспетчера `create-artifact.md` совпадает с замыслом «режимы различаются только входом»: три подраздела
входа, один общий «Порядок» с ветвью сдачи по состоянию комплекта, короткий раздел «Режим C — change» (состав
и запреты). Ссылки на шаги режима — именами, не номерами. Скилл `/change` для Cursor и надстройки 14 типов
работают без изменения содержания.

## Границы

- Надстройки типов (типовые задачи, карта затронутых, обязательные вопросы, идентификаторы) по содержанию не
  меняются — в каждом скилле типа правится одна строка-ссылка.
- Шаблоны типов не трогаются; `task.md` и `delta-report.md` — только слова «на шаге 2 режима C» → имя шага.
- Заголовок «## Режим C — change (изменение по постановке)» сохраняется дословно (Р-3, если владелец не решит иначе).
- Перенос текста — дословный; переформулировки шагов 1–3 и сдачи в этот трек не входят (отдельные замечания — списком
  в сдаче, не правками).
- Прибор: только строки сообщений и комментариев `delta_report.py`; поведение не меняется. Р-2 (отчёт дельты без
  `--task`) — отдельная постановка прибору, если владелец выберет (а).
