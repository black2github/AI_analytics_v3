Задача среза 0 (SC-02, SC-06):

2. В `canon/_meta/skills/create-skill.md` добавь норму каркаса скилла с режимами по SC-02: порядок разделов
   `## Вход` → `### Вход reverse (режим A)` → `### Вход forward (режим B)` → `## Порядок` (общие шаги один раз,
   сквозная нумерация) → `## Режим C — change` → границы/специфика → правила всех режимов → самопроверка/выход.
   Формулируй самодостаточно, как норму для автора скилла: что в каждый раздел входит, чего в нём быть не должно
   (в «Вход reverse» — только сбор источников из выгрузки; в «Порядок» — ничего, что зависит от режима). Без
   идентификаторов решений (SC-NN) и без упоминания «переворота»: норма описывает, как устроен скилл, а не историю.
   Встраивайся в существующую структуру файла: раздел «Каркас `_meta/skills/<name>.md`» уже есть — расширяй его
   (каркас для скилла с режимами как вариант основного), не заводи параллельный.
3. Приведи `canon/_meta/skills/create-function.md` к этому каркасу как образец для группы 2: шаги сбора источников из

   можно только связки («в режиме A», «см. шаги N–M»), и каждую такую переформулировку перечисли в сдаче. Ничего
   не сокращай и не «улучшай» по дороге: срез проверяет структуру, не содержание.
