# Шаги владельца: репозиторий зеркала, push, запуск облачной сессии

Дата: 2026-10-29. Зеркало собрано локально в `C:\tmp\skill-core-cloud` (ветка `main`, один коммит, без remote).
Все действия ниже выполняет владелец; сессия analyzer к облаку не обращается.

## 1. Создать репозиторий на GitHub

На github.com под аккаунтом black2github: **New repository** → имя `skill-core-cloud`, **Private**, без README, без
.gitignore, без лицензии (репозиторий должен быть пустым, иначе push отклонится).

## 2. Привязать и отправить зеркало

PowerShell, по одной команде:

```
git -C C:\tmp\skill-core-cloud remote add origin https://github.com/black2github/skill-core-cloud.git
```

```
git -C C:\tmp\skill-core-cloud push -u origin main
```

Ожидание: push примерно 39 МБ, в ответе `main -> main`, `branch 'main' set up to track 'origin/main'`. Если GitHub
запросит вход — тот же способ, что для analyzer (учётные данные уже сохранены, обычно запроса нет).

Проверка после push:

```
git -C C:\tmp\skill-core-cloud status -sb
```

Ожидание: `## main...origin/main`, без списка файлов.

## 3. Запустить облачную сессию

В claude.ai/code: новая облачная сессия → репозиторий `black2github/skill-core-cloud` (если репозиторий не виден —
в настройках GitHub-приложения Claude дать ему доступ к этому репозиторию) → ветка `main` → модель Fable 5.1.

Первое сообщение — целиком раздел «Текст первого сообщения (копировать целиком)» из файла
`Постановка для облачной сессии — срез 0 — каркас скилла и образец на create-function (2026-10-29).md`
(тот же файл лежит в зеркале: `skillCore/…`).

Дальше сессии ничего не нужно: все решения — в файле решений, проверки — в README зеркала. Если сессия задаёт
вопрос в чате вместо `skillCore/questions.md` — ответ «запиши вопрос в skillCore/questions.md и остановись по
SC-07», решение принимается здесь.

## 4. Когда сессия сдаст срез 0

Сообщить сессии analyzer: «срез 0 сдан, ветка skill-core/0-skeleton». Дальше — разбор сдачи здесь
(`git -C C:\tmp\skill-core-cloud fetch origin` выполняет сессия analyzer сама), отметка SC-09 — ваша.
