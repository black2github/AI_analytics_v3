## Возврат результата

Ветка `skill-core/<N>-…` в зеркале → `git format-patch` → в клоне канона на ветке `meta/skill-core-<N>`
`git am -p2` → MR владельца → master; сдачи и A/B-материалы копируются сюда и коммитятся в analyzer.
