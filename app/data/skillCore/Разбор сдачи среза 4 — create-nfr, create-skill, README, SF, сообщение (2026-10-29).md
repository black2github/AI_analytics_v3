## Р-1 — имя файла постановки среза 4 (наблюдение 1 сдачи, подтверждено)

Имя `Постановка для облачной сессии — срез 4 — … (2026-10-29).md` — 266 байт в UTF-8 при лимите 255 байт на ext4; на
Linux `main` зеркала не выписывается без `skip-worktree`/sparse-checkout. Ошибка моя (имя собрано из перечня объёма).
Предложение: после ff-вливания ветки переименовать файл в `main` зеркала и в app/data в
`Постановка для облачной сессии — срез 4 — create-nfr, create-skill, README, SF, сообщение (2026-10-29).md`
(по образцу имени сдачи; ~150 байт), поправить ссылки в README трека и плане; правило «имя файла ≤ 255 байт UTF-8, для
кириллицы — до ~120 символов» — в память и в README трека. Рекомендация — **да**, делаю сам одним коммитом в `main`.
