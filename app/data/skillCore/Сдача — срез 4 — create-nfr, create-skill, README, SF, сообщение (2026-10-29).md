1. **Имя файла постановки среза 4 не помещается в лимит Linux.** `Постановка для облачной сессии — срез 4 — … (2026-10-29).md`
   — 266 байт в UTF-8 при `NAME_MAX` 255 (ext4): `git pull`/`checkout main` на Linux падает с «File name too long», и
   ветка `main` зеркала на Linux без обхода не выписывается (на Windows/NTFS лимит 255 символов, не байт — там проблемы
   нет). В сессии файл помечен `git update-index --skip-worktree` и прочитан через `git show origin/main:<путь>`;
   worktree для проверки патчей собран через `sparse-checkout set canon`. Рекомендация: переименовать файл в `main`
   (например, `Постановка … — срез 4 — create-nfr, create-skill, README, SF, сообщение (2026-10-29).md`, по образцу
   имени сдачи), иначе любой Linux-клон зеркала (CI, следующая облачная сессия) споткнётся на том же.
2. **Кавычки в оговорке 3 `create-skill.md`.** В постановке абзац-указатель дополнений процитирован как «Общие шаги —
   „Порядок“ скилла …» (внутренние кавычки „“ — вложение в «…»), в пяти файлах дополнений абзац записан «Общие шаги —
   «Порядок» скилла …». Текст применён дословно по постановке; расхождение — только типографика вложенных кавычек,
   смысл и слова те же. Отмечаю на случай, если владелец захочет единообразия.
