## Замечания к тексту (не правки)

1. Пункт «Режим:» теперь читается «задачу ставит аналитик — вход — подраздел ниже, состав и запреты — раздел «Режим C —
   change»» — три тире подряд; можно разбить точкой с запятой.
2. Шаг 6 C, перенесённый в сдачу, говорит «ровно одно из четырёх» происхождений, а соседняя новая фраза добавляет
   пятое — «страница источника» при заходе по выгрузке. При следующем проходе сформулировать как одно целое.
3. Шаг 8 C в сдаче начинается «Порядок сдачи строгий: (а)…» — слово «Порядок» совпадает с названием раздела.
4. Ветвь «принятый комплект» шага самопроверки начинается с «**Самопроверка** из корня репозитория» — повтор
   названия шага (дословный перенос).
5. Первый абзац раздела C («„Порядок“ и правила всех режимов действуют, кроме сверки с выгрузкой…») после правки
   верен, но частично повторяет новую строку «Заход: …».
6. Каркас create-skill держит в «Порядке» отдельный шаг «Спорные места», в `create-artifact` его нет (спорные места —
   в сдаче нового комплекта); структура совпадает по разделам, а не по шагам.
7. Скиллы типов подразделов «Вход change» не имеют — вход берётся у диспетчера. Пункт чек-листа create-skill
   «разделы в порядке каркаса» для них читается буквально; стоит оговорить, что вход change у скиллов типов — в
   `create-artifact`.
8. Вне скоупа: `link_debts.py` :14 (прибор) — комментарий «(create-artifact, шаг 6)», устаревшая нумерация давнего
   «Порядка»; поправить при следующей правке прибора.
