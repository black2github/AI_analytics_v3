### 2. `create-skill.md` окончательно (коммит 2 по `canon/`)

Раздел «Каркас скилла с режимами (reverse / forward / change)» дополняется тем, что выяснилось на срезах 1–3; поведение
каркаса не меняется, добавляются четыре оговорки. Текст дословно (место — указано):

1. В markdown-каркасе раздела между `### Вход forward (режим B)` и `## Порядок` — строка `## Gate (если был)` с
   комментарием `<условия, при которых скилл не стартует; от режима не зависят>`; в таблицу «Что входит в каждый раздел»
   — строка: `| `## Gate` (если был) | условия, при которых скилл не стартует, одинаковые для всех режимов; место — между
   подразделами «Вход» и «Порядком». У скиллов, где Gate стоит после разделов путей и контуров (`create-contract-call`),
   «Порядок» идёт сразу за «Входом», а Gate — на своём месте ниже | условия, зависящие от режима (их место — подраздел
   «Вход» режима) |`.
2. После абзаца «Ссылки на шаги: …» — новый абзац: `Подразделы входа с собственными заголовками (например, «Reverse —
   источник», «Reverse — где искать в коде») остаются внутри «Вход reverse» заголовками уровнем ниже (`####`); их имена не
   меняются — на них ссылаются по названию.`
3. Там же следующим абзацем: `Дополнения к диспетчеру (`create-data-model`, `create-contract-call`, `create-controls`,
   `create-rbac`, `create-print-form`) общих шагов не несут: их `## Порядок` — один абзац-указатель «Общие шаги —
   „Порядок“ скилла `create-artifact` (тип `<тип>`): документ по шаблону, матрица, спорные места, чек-лист, selfcheck,
   отчёт, коммит. Специфика типа — разделы ниже.», а специфика типа — разделы после него.`
4. Там же следующим абзацем: `Скилл, у которого режим задаётся полем запроса (`create-nfr`: `ingress` со значениями
   `reverse`, `update`, `forward`), держит тот же каркас; значения поля перечисляются в заголовках подразделов входа в
   скобках после буквы режима, `update` относится к тому подразделу, чей источник он использует.`

Другие правки `create-skill.md` не нужны; если по ходу увидишь расхождение каркаса с тем, что реально сделано в 13
скиллах, — вопрос в `questions.md`, не правка.
