2. **Р-2 (б): «источник page_id N не сверялся — `--sources` не задан»** (~426): без `--sources` строк на карточках
   нет; вместо них одна строка на комплект, в блоке сводных строк перед ИТОГО:
   `i карточек с происхождением из Confluence (confluence_page_ids): N; выгрузки в репозитории нет — сверка с
   источником: selfcheck.py --sources <архив src-<service-id>>`. Перечень карточек (путь, page id) — в `--out`
   строками `OUT_ONLY`, как у сторожа сообщений контролей. При N = 0 строка не печатается. С `--sources` — как сейчас.
3. **✗ «`confluence_page_ids` задан, но id не распознаны — reverse-карточка выпала бы из сверки с источником»** (~420):
   метка ✗ и код возврата не меняются; текст нейтральный в обоих режимах: «`confluence_page_ids` задан, но id не
   распознаны — ключ сопоставления по странице не читается (сверка с источником и дельты по page id карточку не
   найдут); формат по шаблону: inline-список».
4. **«i сверка сообщений карточек контролей с источником не выполнена: …»** (~920–946): гейт
   `if ctx.sources is None: return [], True` — без `--sources` ни строки, ни перечня в `--out`. С `--sources` — как
   сейчас (включая «страница не указана» и «нет таблицы с колонкой сообщения»).
5. **Предупреждение о маркере сокращения** (`kitcheck/checks/card_form.py`): формулировка по режиму. С источником —
   прежняя («…проверьте, что справочники и перечни источника перенесены целиком»); без источника — «…проверьте, что
   перечень приведён целиком». Как проверка узнаёт режим — по тому, что есть в контексте (`src_text`/`sources`);
   если удобнее, нейтральный текст в обоих режимах — скажите, это допустимо, но тогда строка эталона с `--sources`
   изменится и baseline придётся переснять осознанно.
