# Сообщение командам — обновление утилит канона (master 05b1faa, 2026-10-30)

Для всех команд, работающих по канону (координаторы и исполнители). Команде КК отдельно передано то же с её числами. Передаёт владелец канона.

---

Коллеги, в каноне (`_meta/tools/`) сняты два ложных ✗ гейта карточки на законно перенесённых карточках функций, обновите клон перед прогонами:

```
git -C <клон канона> pull --ff-only
```

1. **Тяжёлая пара, ячейка начинается абзацем с отступом.** Если в источнике ячейка «Что делает функция» (или другая тяжёлая пара) начинается абзацем с отступом, эталон конвертера даёт её цитатой `> …`, а в карточке цитаты запрещены (вложенность — списками). Раньше сторож структуры тяжёлых пар искал начало ячейки вместе с `> `, не находил его и давал ✗ «содержимое/структура тяжёлых пар расходится с эталоном конвертера» при любой законной раскладке. Теперь маркеры цитат при поиске снимаются; раскладка списком проходит с i-строкой «тяжёлая пара разложена markdown-списком …». Потерянное или склеенное в одну простыню содержимое — ✗ как прежде.

2. **Составной номер шага без отступа в источнике.** Если в источнике шаг «4.1» выгружен без отступа (артефакт разметки страницы), сторож нумерации требовал вложить шаг по глубине номера, а сторож вложенности — оставить на уровне источника, и любая форма карточки давала ✗. Теперь шаг, вложенный ровно по глубине составного номера при более мелком уровне в источнике, проходит со строкой «i поведение: шаг «4.1» вложен по номеру (уровень 1), в источнике отступ 0 — артефакт разметки источника, профиль принят», видимой и при ✓. Шаг глубже номера, одиночный номер не на своём уровне, источник глубже карточки (выпрямление) и потеря шага — ✗ как прежде. Сторож нумерации не менялся.

Карточки под временные обходы (`- >`-маркер, блок кода с выходом конвертера, выпрямление шагов) править не нужно — если такие обходы уже сделаны, верните дословную форму. Команды, ключи, отчёты и коды возврата те же; эталонный комплект проходит без отличий. Бандл экспортёра не затронут. Вопросы — владельцу канона.
