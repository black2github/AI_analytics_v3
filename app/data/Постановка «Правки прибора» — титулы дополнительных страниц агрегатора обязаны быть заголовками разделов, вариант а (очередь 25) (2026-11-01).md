## Решение владельца

Вариант (а) из вашего разбора: правило «равенство title главной странице проходит первым» (30.10) остаётся только для title ГЛАВНОЙ страницы; сверка титулов ДОПОЛНИТЕЛЬНЫХ страниц по заголовкам разделов выполняется у любого агрегатора, независимо от того, совпал ли title карточки с главной или снят маркер базового (EXTINT). Одна логика для обычных агрегаторов и базовых контрактов внешних АС.

## Целевое поведение

- `check_title` (card_source.py :754–775): шаг 1 — title главной: равенство (:754) или снятый маркер базового (:759) → ✓ по главной; шаг 2 — для каждой доп. страницы: её title должен быть заголовком раздела карточки (как сейчас для агрегаторов с несовпавшим title) → иначе ✗ с id и названием страницы. Шаг 2 выполняется всегда при наличии доп. page_ids.
- Освобождения: доп. страница без файла источника — i «без источника», не ✗; существующие правила нормализации заголовков (ID в скобках, маркеры, кавычки) — без изменений.
- Ограничители: карточка с одной страницей — поведение прежнее; агрегатор, у которого титулы доп. страниц уже разделы, — отчёт прежний.
