## Правило, как реализовано

1. **Объявлена, но не введена.** Множество A — ID задач из `coordination-state.md` и
   `coordination-log.md` по трём формам:
   - «`<ID>` введена (введены) в (промышленную) эксплуатацию»;
   - «`<ID>` в (промышленной) эксплуатации»;
   - «введённые задачи …: X, Y» (в том числе ячейкой таблицы состояния).

   Множество B — теги `git tag --merged HEAD --list 'src/*'`. A \ B → строка
   `⚠ задача объявлена введённой, тега src/<ID> нет: <ID> (журнал: coordination-log.md, строка N) —
   ввод делается run-history (гид, «Ветки и теги»)`; для состояния — «(состояние: …)». Одна строка на
   задачу, место — первое объявление.
2. **Введена, но числится замороженной.** Строка `sandbox/confluence-unapproved-jira-pages.md` с задачей
   из B в колонке `unapproved_jira` (без шапки — по всей строке) и строка `inventory.md`, основание
   которой содержит «заморожено `<ID>`» при `<ID>` из B → ⚠ по странице. Перечень ограничен 30 строками
   с хвостом «… и ещё N».
3. Есть журнал, состояние или список, но нет `.git` или git не отвечает — одна строка
   `i теги задач не проверены (нет git)`. Нет ни журнала, ни состояния, ни списка — молчание (поэтому
   стенд и эталон не затронуты). Корень — родитель `--docs`; в репозитории документации, где комплект в
   корне, — сам `--docs`.

## Отличия от постановки и ограничители

- **ID — только рядом с глаголом, не «в той же строке записи».** Запись журнала КК — одна строка до
  2 000+ символов: в строке 339 рядом с «введены в эксплуатацию» стоят 17 ID (GBO-…, OQ-…, CMP-…,
  INTC-…). Правило «любой ID в той же строке» дало бы на КК 15 ложных ⚠ (9 GBO, 3 OQ, 2 CMP, 1 INTC). Взята группа ID
  непосредственно перед глаголом, между ними — не больше трёх слов без ID и без `;`/`|`. Тест
  `test_unrelated_ids_in_long_record_not_declared`.
- **Сокращённые номера раскрываются:** «TEAMTB-3716/-3846/-3969 введены» → три задачи (так в журнале КК).
- **Глагол обязателен для «в эксплуатацию».** «TEAMTB-5 — ввод в эксплуатацию 30.10» — план, не факт;
  «в эксплуатации» (состояние) глагола не требует.
- **Отрицание и будущее** в просвете между ID и глаголом («НЕ», «ещё не», «планир…», «будет»,
  «ожида…») — не объявление. Тест `test_not_introduced_and_planned_silent` (6 формулировок, включая
  «страница введена GBO-95842» и «введены и устранены» из журнала КК).
- **Тег на другой ветке не считается** — только достижимые из HEAD (`--merged HEAD`). Тест
  `test_tag_on_other_branch_not_counted`.

Асимметрия ошибок: сторож только предупреждает; пропуск объявления в нестандартной формулировке —
тихий (⚠ не будет), ложное срабатывание закрыто тестами на НЕсрабатывание. Если в журналах команд
встретятся иные формы объявления — расширять `_DECL_RE` / `_LIST_RE` с тестом.
