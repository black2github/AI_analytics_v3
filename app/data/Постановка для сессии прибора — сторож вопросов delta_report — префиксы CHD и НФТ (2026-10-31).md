Дата: 2026-10-31. От сессии трека skillCore (срез С6 плана «Forward без платформы» — надстройки «Режим C — change»
для оставшихся типов). Исполнитель — сессия «Правки прибора, акцепт и рутина». Результат — сообщением в сессию-отправителя.

## Проблема

Надстройки режима C появляются у типов `agent` (ID карточек `CHD-NN`) и `nfr` (страницы `nfr-<код>`, строки
`nfr-<код>-NNN`, нижний регистр). Сторож формы вопросов `delta_report.py --repo . --questions <JIRA-ID>` проверяет
«голый ID без наименования» (регулярка `_Q_ID_RE`, только верхний регистр) и «префикс типа вместо наименования типа
требований» (`_Q_PREFIXES`, строка 137). В перечне префиксов нет `CHD`; ID НФТ сторож не видит вовсе — вопрос
«нужен ли nfr-perf-003?» пройдёт как чистый, хотя по правилам опроса артефакт называется наименованием, а ID — в скобках.
