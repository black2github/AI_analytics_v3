## Что делает `--write`

- **README по шаблону** (есть «## Операции»): заменяются только таблицы «Операции» и «Форматы
  сообщений»; назначение, «О системе», текст разделов вне таблиц, «Примеры обмена» и прочие
  разделы — байт в байт. Раздела «Форматы сообщений» нет, а форматы есть — раздел вставляется
  после «Операций» с фразой шаблона; есть, а форматов нет — остаётся с пустой таблицей
  (ручной текст раздела не снимается).
- **Строки**: группы по каналу в порядке словаря шаблона, канал вне словаря («—») — последним;
  внутри — по номеру; дубль ID — обе строки (сценарий 7); «Название» = `title`, без него «—»
  (развилка 7а); таблицы выровнены пробелами.
- **README каталога без README** — по шаблону: `id: EXTINT-<AS>-000`, `type:
  external-integration-registry`, «Назначение АС: в источниках не задано.», шапка-указатель,
  «О системе» (Система — имя АС; Каналы, Среда и адреса, Документация АС — «в источниках не
  задано / не заданы / не задана»; Примеры — ссылка, если есть `examples/`, иначе «—»;
  Вложения — только при `files/`), таблицы, «Примеры обмена». Имя АС — из «## Реестр систем»
  корневого README, иначе из заголовка «### <имя> — папка [`<папка>/`]» прежнего реестра
  карточек, иначе код папки. EOL нового файла — как у карточек каталога.
- **Корневой README**: при разделе «## Реестр систем» пересобирается его таблица (`Система |
  Папка | README | Карточек`); имя системы из существующей строки сохраняется; текст вне таблицы
  — байт в байт. Раздела нет — файл не трогается, строка `i` (перевод корня — шаг 4 среза С4).
- **Отказ — по файлам** (файл не тронут, код 2; остальные пишутся):
  - README не по шаблону (развилка 3а) — перевод отдельным заходом со сверкой фактов;
  - строка таблицы без файла, строка реестра систем без папки — снимает человек (развилка 5);
  - в каталоге карточка со сломанной шапкой или без `kind` — разложить по таблицам нельзя, а
    молча пропустить строку — потеря.
- EOL и BOM сохраняются; запись атомарная (временный файл и замена); неизменённый файл не
  перезаписывается (тест на `mtime`).

Почему отказ по файлам, а не на весь прогон: на trunk четыре README не по шаблону; отказ целиком
заблокировал бы создание README остальных папок — шаг 3 среза С4.
