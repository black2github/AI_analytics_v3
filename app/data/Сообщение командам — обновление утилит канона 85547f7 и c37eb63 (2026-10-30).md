# Сообщение командам — обновление утилит канона (master 85547f7 и c37eb63, 2026-10-30)

Для всех команд, работающих по канону (координаторы и исполнители). Команде КК отдельно передано то же с её числами (30.10). Передаёт владелец канона.

---

Коллеги, в каноне (`_meta/tools/`) два обновления утилит, поведение гейтов по существу не меняется, но перед следующими прогонами обновите клон:

```
git -C <клон канона> pull --ff-only
```

1. **Покрытие источника** (`source_coverage.py`, master 85547f7). В сводке два новых класса непокрытия. «Снято с миграции» — страницы, помеченные в выгрузке DELETE или [DRAFT], либо названные в описи `inventory.md` словами «снято с миграции» или «черновик» в основании или целевом типе (раньше их приходилось маскировать словом reference-only). «Каталоги-узлы без собственной страницы» — каталоги выгрузки с дочерними страницами, но без своей (раньше печатались как «нарушение инварианта имён выгрузки»); дефектом выгрузки теперь считается только пустой каталог без страницы и без детей. Число пробелов миграции и поведение `--strict` не меняются. Словарь классов в `_meta/migration/prompt-plan.md` дополнен: снятое с миграции называйте в описи этими словами.

2. **Глоссарий в selfcheck** (master 85547f7). Для документов `type: glossary` не применяются сторож полноты кавычечных литералов источника и сторож выносок «>»: глоссарий — документ определений, а выноска-делегирование предписана его шаблоном. Под файлом печатается строка «сторож литералов не применяется к глоссарию». Для `type: domain-vision` снят только сторож литералов. Остальные проверки глоссария (ссылки, frontmatter без `status`, H1, отсутствие OQ и ссылок на sources) действуют.

3. **Перестройка прибора** (master c37eb63). Проверки карточки вынесены из `normalize_tables.py` в пакет `kitcheck/checks/card_*.py`; в `normalize_tables.py` остался нормализатор таблиц. Команды, ключи, отчёты и коды возврата те же (`selfcheck.py`, `normalize_tables.py --check`, `normalize_tables.py --branch-form`, `link_debts.py`, `transfer_gate.py`, `source_coverage.py`); эквивалентность сверена на двух комплектах строка в строку. Если у вас есть собственные скрипты, импортирующие функции проверок из `normalize_tables`, старые имена работают через переадресацию ещё один релиз: переведите их на `kitcheck.checks`.

Бандл экспортёра не затронут. Вопросы — владельцу канона.
