# Сообщение координатору КК — срез канона `0ea0b7f`

Дата: 2026-10-10. Передаёт владелец канона.

## Что изменилось в каноне

Срез `0ea0b7f` (MR `meta/readme-self-description`): раздел «Условные обозначения» в `docs/README.md`
комплекта стал самоописанием комплекта. Изменены четыре файла канона:

- `_meta/templates/docs-readme.md` — раздел «Условные обозначения»: полная таблица префиксов
  (добавлены `GLO`, `SM`, `NTF`, `INTC` с двумя состояниями, `LIBC`, `CHD`; `PLT` помечен как
  переходный реестр), подраздел «Подсервисы» (только у сервиса из частей), идентификатор статусной
  модели, таблица «Поля frontmatter» (`id`/`partOf`, `type`, `service`, `title`,
  `confluence_page_ids`). Имена подразделов менять нельзя: по ним раздел читают инструменты и
  агенты вне комплекта.
- `_meta/skills/create-docs-readme.md` — шаг 5: как собрать раздел по факту frontmatter карточек.
- `_meta/tools/selfcheck.py` — новый сторож «условные обозначения README»: только ⚠, вердикт не
  меняет. Сигналит, если префикс ID комплекта не описан в таблице типов, идентификатор `SM-…` не
  назван, поля frontmatter не описаны, таблица кодов частей названа не «Подсервисы».
- `_meta/structural-facts.md` — запись SF-02 об именах разделов README.

## Что сделать координатору

1. Принять срез по обычному порядку: обновить клон канона до `master` `0ea0b7f`, выполнить
   `accept_canon.py --profile README.md` в `src-business-cards`, обновить блок норм в
   `coordination-state.md` (изменённые разделы: шаблон README, скилл `create-docs-readme`).
2. Запустить гейт. Ожидаются новые ⚠ от сторожа «условные обозначения README»: у комплекта КК
   раздел «Условные обозначения» в `docs/README.md` отсутствует. Это не брак, вердикт не меняется.
3. При ближайшей правке `docs/README.md` (не отдельным заходом): выполнить скилл
   `create-docs-readme` в режиме **sync** — он соберёт раздел «Условные обозначения» по шаблону:
   все префиксы, встречающиеся в комплекте (у КК сейчас, среди прочих, `INTC`, `SM`), идентификаторы
   статусных моделей частей, таблица «Поля frontmatter». Отдельный заход ради этого не требуется.

## Зачем

README комплекта читают внешние потребители как паспорт сервиса: из него берут контуры, части,
типы документов и статусную модель. Пока раздел молчит, читатель применяет собственные умолчания и
может не распознать типы комплекта (`INTC`, `LIBC`). Полное самоописание снимает это без каких-либо
изменений в самих карточках.
