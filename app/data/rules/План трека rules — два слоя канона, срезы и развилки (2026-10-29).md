## Цель

Правило канона: у канона два слоя — **ядро** (нужно сервису всегда: `_meta/skills`, `_meta/templates`, `_meta/rules`,
общие инструменты прибора) и **миграционный конвейер** (нужен, пока комплект строится из выгрузки Confluence:
`_meta/migration/`, инструменты выгрузки и сверки с источником). У миграционного слоя — признак жизни на сервисе:
включён, пока есть выгрузка и `src-<service-id>` не заморожен; выключен после заморозки `src` и переноса в
`docs-<service-id>`. Доказательство правила — прибор: ни один сторож ядра не считает отсутствие выгрузки дефектом, ни
один миграционный сторож не запускается без неё молча. Результат: выключение reverse у сервиса — штатная операция,
описанная в гиде, а не побочное свойство отдельных утилит.

## Границы

- Скиллы не делятся и не переезжают (решение 29.10 по п. 1; трек skillCore закрыт). `_meta/migration/` остаётся на месте:
  разметка слоя — текст и таблица, не перемещение файлов.
- Шаблоны типов (`_meta/templates`) не трогаются.
- Асимметрия ошибок сохраняется: «нейтральный режим без источника» не скрывает потерю требований — сверка с выгрузкой в
  `docs-*` остаётся доступной (`--sources` на архив `src-*`), а сторожа ядра без источника отрабатывают, а не пропускаются.
- Без новых полей в манифесте и шапках карточек, если владелец не решит иначе (Р-3).
- `confluence_page_ids` не снимаются и не объявляются «устаревшими» ни в одном режиме (пояснение владельца 29.10): до полного
  завершения миграции — переноса всех страниц с требованиями, которые на момент миграции ПРОМ-среза были в разработке, — это
  рабочий ключ: изменение на ранее мигрированной странице соотносится с карточками, у которых тот же page id в списке.
  Правило мягкое, но при выборе между вариантами предпочтение — тому, который этот ключ сохраняет и держит на виду.

## Развилки владельцу (до среза 1)

- **Р-1. Форма разметки слоя.** (а) Таблица «инструмент → слой → когда включён → поведение без выгрузки» в README прибора
  плюс подраздел правила в гиде `reference.md`; (б) то же плюс строка `Слой: ядро | миграция` в шапке каждой утилиты и
  каждого модуля `kitcheck/checks/*.py` — проверяемо сторожом (SF или тест прибора). Рекомендация — **(б)**: таблица в
  README расходится с кодом при первом же новом сторожe, строка в шапке — один дом у факта рядом с кодом, тест на полноту
  дешёвый.
- **Р-2. Перенесённые карточки без выгрузки.** В `docs-*` у карточек есть `confluence_page_ids` (происхождение), а
  `sources/` нет — `selfcheck` печатает «не сверялся — `--sources` не задан» на каждой, навсегда. (а) Оставить как есть
  (информационный перечень); (б) в режиме репозитория документации (как его определяет гейт: `tasks/` есть, `sources/` нет,
  матрица в корне) — одна сводная строка «N карточек с происхождением из Confluence; выгрузки в репозитории нет, сверка —
  `--sources <архив src>`» вместо N строк; `confluence_page_ids` остаются — это не только происхождение, но и ключ для
  сопоставления будущих дельт по страницам, ещё не завершившим разработку (пояснение владельца 29.10); сводная строка должна
  называть число карточек с page id и путь включения сверки, а не прятать ключ. Рекомендация — **(б)**: это и есть критерий «для карточек без источника молчит», шум по N строк на каждом прогоне приучает не читать отчёт.
- **Р-3. Как определяется «слой выключен» на сервисе.** (а) Вычислять по раскладке, как гейт (нет `sources/`, есть `tasks/`,
  матрица в корне); (б) явный признак в `gpb-manifest.json` или README комплекта. Рекомендация — **(а)**: один дом у факта
  уже есть (гейт), новое поле — второй дом и новая обязанность команды.
- **Р-4. Исполнители.** Текст канона (гид, README прибора, kitcheck README) — эта сессия или новая локальная; прогон п. 3 и
  правки сторожей с тестами — сессия прибора (Opus 5.5) по постановке файлом в этом каталоге. Облачная сессия не нужна.

## Риски и ограничители

- **Сторож ядра, реализованный через индекс источников.** Часть проверок читает индекс выгрузки попутно (например, сверка
  нормализации таблиц, «молчание источника»); перевод в нейтральный режим должен сохранять их работу с `--sources`.
  Ограничитель: каждому переводу — тест, что с источником поведение не изменилось (эталон = baseline).
- **Молчание вместо сигнала.** Сводная строка Р-2 (б) не должна скрывать карточку, у которой `confluence_page_ids` задан, а
  id не распознаны (П-8, ✗ остаётся ✗ в любом режиме).
- **Два дома у факта.** Таблица в README прибора и строки `Слой:` в коде (Р-1 (б)) расходятся без сторожа — тест полноты
  в срезе 3 обязателен, иначе выбирать (а).
- **Сроки КК.** Первый репозиторий `docs-*` с перенесёнными карточками появится при переносе ПРОМ-среза КК в EAN; если
  перенос раньше среза 3, команда увидит N строк «не сверялся» — предупредить в сообщении о переносе.
