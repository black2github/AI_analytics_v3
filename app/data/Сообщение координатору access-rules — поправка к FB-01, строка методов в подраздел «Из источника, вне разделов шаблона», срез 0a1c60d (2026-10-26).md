## Что меняется

В сообщении о закрытии FB-01 я указал перенести строку «Какие методы закрывает функция» в раздел
«Доступность». Это место отменяется: метод API принадлежит контракту, а в «Доступности» его пришлось бы
править при смене реализации. Правило записано в канон, срез `0a1c60d` (шаблон function §6 и чек-лист
п. 11, гид «Постоянные правила», промпт ревьюера п. 3): сведения источника, для которых в шаблоне нет
слота, переносятся дословно с лейблом источника в подраздел H2 «Из источника, вне разделов шаблона» в
конце карточки; когда появится карточка контракта метода — ссылкой на неё. Подраздел не дублирует слоты
шаблона, ревью проверяет в нём только дословность.

## Что сделать

1. Принять срез канона `0a1c60d` (`accept_canon`), перезапустить selfcheck.
2. В `docs/srs/function/bank/fun-bnk-01-view-execution-history.md` (дозаход по форме c7169b6 уже выполнен):
   из «Доступности» убрать «, закрывает метод `/admin/access-rule/{id}/history`», в конец карточки добавить:

   ```markdown
   ## Из источника, вне разделов шаблона

   - Какие методы закрывает функция: `/admin/access-rule/{id}/history`
   ```

   Принимает прибор; приёмка акцептующего не нужна. В следующих заходах по функциям (FUN-02 и далее)
   строки «какие методы закрывает» сразу в этот подраздел.
3. Прибор скоро начнёт печатать строку «i подраздел вне шаблона: N строк» — это отметка, не замечание;
   ⚠ будет только если подраздел пуст или стоит не последним H2.
