# Пилот Doc-as-Code: точка возврата (2026-10-05)

Статус-файл для продолжения работы из любой сессии/машины. Память
агента локальна и между ноутбуками НЕ переносится — источник истины
этот файл + git. Новой сессии: «прочитай DOC_AS_CODE_PILOT_STATUS.md,
продолжаем с раздела Очередь».

## Роли

Пользователь — владелец пилота: решения, коммиты/push, акцепты
(`accept_canon.py`), передача промптов агентам. Агент (Claude в этом
репо) — владелец канона: калибровки прибора, шаблоны/промпты/гид,
техприёмка сдач. Гейты CLAUDE.md обязательны (коммит только по
запросу, точечный git add, план перед крупным, вопросы вместо
угадывания).

целевой ДО записи; стенд/канон CRLF, app/data — LF).

## Как запускать

- Гейт (из корня стенда): `python ../docs-o2new/_meta/tools/selfcheck.py
  --docs docs --sources confluence --baseline <принятый> --out <отчёт>
  --journal sandbox/journal.txt`
- Тесты analyzer (venv сломан): `PYTHONPATH="$PWD;$PWD/.venv/Lib/site-packages"
  PYTHONIOENCODING=utf-8 <системный python3.12> -m pytest tests/... -q -o addopts=""`
- Accept среза канона: `python <канон>/_meta/tools/accept_canon.py
  --profile <стенд>/README.md` — профиль коммитит сам.
